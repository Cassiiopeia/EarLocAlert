# Pretendard

이 앱은 Pretendard 글꼴을 사용합니다.

| | |
|---|---|
| 저작자 | 길형진 (orioncactus) |
| 라이선스 | SIL Open Font License 1.1 |
| 원본 | https://github.com/orioncactus/pretendard |

SIL OFL 1.1 은 상용 앱 내장 사용을 허용합니다. 글꼴 파일 자체를 판매하지
않으며, 원본 저작자 표기를 유지합니다.

## 포함한 굵기

`AppTypography` 가 실제로 쓰는 넷만 넣었습니다. 한 종이 약 1.5MB 라
전부(9종) 넣으면 사용자가 내려받는 용량이 13.5MB 늘어납니다.

| 파일 | weight | 쓰는 곳 |
|---|---|---|
| Pretendard-Regular.otf | 400 | 본문, 보조 설명 |
| Pretendard-Medium.otf | 500 | 알림 화면 시각 |
| Pretendard-SemiBold.otf | 600 | 화면 제목 |
| Pretendard-Bold.otf | 700 | 장소명, 대표 수치 |

새 굵기를 쓰려면 파일과 `pubspec.yaml` 선언을 함께 더해야 합니다.
