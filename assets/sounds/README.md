# 알림음

**이어폰(줄·USB-C·블루투스)이 연결된 경우에만 재생된다** (F3.7). 미연결 시에는
파일이 있어도 재생하지 않는다 — 스피커로 새는 것을 막기 위해서다.

해제할 때까지 **반복 재생**된다. 진동은 반복되는데 소리만 한 번 나고 마는 것은
졸다 깬 사용자에게 약한 알림이다.

## 프리셋 목록

장소마다 하나를 고른다 (이슈 #121). 목록은 `lib/core/domain/alert_sound.dart` 의
`SoundPreset` enum 이 단일 출처다.

| 파일 | 이름 | 성격 | 길이 |
|---|---|---|---|
| `alert.wav` | 기본음 | 상승 3음 차임 | 1.5초 |
| `bell.wav` | 종소리 | 두 번 타종, 비조화 배음 | 2.4초 |
| `electronic.wav` | 전자음 | 짧게 세 번, 강함 | 1.5초 |
| `siren.wav` | 사이렌 | 주파수 스윕 2회 | 1.9초 |
| `chime.wav` | 차임 | 부드러운 하강 3음 | 2.6초 |

## 전부 합성한 파형이다

**받아온 음원이 하나도 없다.** 라이선스가 조금이라도 어긋나면 AdMob 계정과 앱이
함께 위험해지는데, 계산으로 만든 소리에는 그 여지가 없다. 생성 스크립트가
레포에 남아 있는 한 출처가 영원히 증명된다.

```bash
python tool/gen_alert_sound.py      # alert.wav (기본음) — 단독
python tool/gen_preset_sounds.py    # bell · electronic · siren · chime
```

기본음이 스크립트가 갈려 있는 이유는 **기존 사용자의 소리가 바뀌면 안 되기**
때문이다. 프리셋을 손보다가 기본음까지 재생성되면 아무것도 바꾸지 않은
사용자의 알림이 달라진다.

## 프리셋을 더할 때

1. 음원을 만들거나 받아온다
2. `assets/sounds/` 에 넣는다
3. `pubspec.yaml` 의 `assets:` 에 한 줄 더한다 — **빠뜨리면 파일은 있는데
   번들에 안 들어가 재생이 실패한다**
4. `SoundPreset` enum 에 한 줄 더한다

`test/core/sound_preset_assets_test.dart` 가 3번을 빠뜨렸는지 잡아준다.

### 받아온 음원을 쓸 경우

**CC0 또는 Public Domain 만 쓴다.** CC-BY 는 앱 안에 저작자 표시 화면이
필요해져 범위가 커진다.

출처를 `ATTRIBUTION.md` 에 기록한다 — 나중에 분쟁이 생기면 그 파일이 유일한
증거다. 지금은 합성 음원뿐이라 그 파일이 없다.

```markdown
| 파일 | 출처 | 라이선스 | 받은 날 | URL |
|---|---|---|---|---|
| xxx.wav | Freesound | CC0 | 2026-09-01 | https://... |
```

## 형식

44.1kHz / 16bit / mono WAV. 피크는 -3dB 근처로 맞춘다 — 실제 재생 크기는
앱의 볼륨 설정(이슈 #86)이 정한다.

**루프 이음새를 확인한다.** 끝에 여백이 없으면 반복 재생 시 소리가 연달아
붙어 정신없어진다.
