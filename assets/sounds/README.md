# 알림음

`alert.wav` — 44.1kHz / 16bit / mono, 약 1.5초.

**이어폰(줄·USB-C·블루투스)이 연결된 경우에만 재생된다** (F3.7). 미연결 시에는
파일이 있어도 재생하지 않는다 — 스피커로 새는 것을 막기 위해서다.

해제할 때까지 **반복 재생**된다. 진동은 반복되는데 소리만 한 번 나고 마는 것은
졸다 깬 사용자에게 약한 알림이다.

## 이 파일은 합성한 것이다

개발 PC 가 내부망이라 음원을 받을 수 없어 파형을 직접 만들었다
(상승 3음 차임 A5·C#6·E6). 재생성·교체는 이렇게 한다.

```bash
python tool/gen_alert_sound.py
```

다른 음원으로 바꿀 때는 **같은 경로·같은 이름**으로 덮어쓰면 된다.
`pubspec.yaml` 의 `assets:` 에 이미 등록되어 있다. 확장자를 바꾸면
`lib/features/alert/data/alert_sound_service_impl.dart` 의 기본 경로도 함께 고친다.
