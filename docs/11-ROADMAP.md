## Phase 0 — 검증 스파이크 (코드 작성 전)

**이 단계를 건너뛰면 안 된다.** [05-PLATFORM](05-PLATFORM.md) 과 [10-DECISIONS](10-DECISIONS.md) 에 "미검증"으로 남은 항목들이 아키텍처를 좌우한다. 지오펜스 패키지를 정하지 않으면 `features/geofence/data/` 를 쓸 수 없다.

목적은 앱을 만드는 게 아니라 **답을 얻는 것**이다. 버릴 코드를 짜도 된다.

| # | 확인할 것 | 실패하면 |
|---|---|---|
| S-1 | **백그라운드 지오펜스 패키지 선정** — 후보들의 현재 유지보수 상태, Android 14 / iOS 17 대응 | 플랫폼 채널을 직접 작성 |
| S-2 | Android 포그라운드 서비스에서 진입 감지 후 5초 내 알림 | F2 목표 수치 하향 |
| S-3 | iOS OS 지오펜스 발화 확인 + 실제 지연 측정 | iOS 기대치를 명세에 반영 |
| S-4 | **블루투스 연결 시 이어폰으로만 소리** (A-05) | 소리 기능 포기, 진동 전용 |
| S-5 | **블루투스 미연결 시 스피커 무음** (A-06) | 출시 불가 — 앱의 계약 위반 |
| S-6 | iOS 반경 50m 발화 여부 | iOS 반경 하한 상향 + 화면 안내 |
| S-7 | iOS 반복 진동 (알림 다중 예약 방식) | iOS 는 1회 알림으로 축소 |
| S-8 | 무음 모드에서 이어폰 소리 동작 | 정책 확정 후 명세 반영 |

**지금 결정하지 않는다.** 사용자가 생긴 뒤에 판단한다.

- 광고 제거 인앱결제

서버 동기화를 붙이면 **위치가 기기 밖으로 나간다.** 개인정보 처리방침과 심사 난이도가 완전히 달라지므로, 그때는 보안 문서를 새로 만든다.

## 실기기 검증 체크리스트

자동화할 수 없는 것들이다. **릴리스 빌드로, 실제 이동하면서 확인한다.**

```
[ ] 앱을 최근 앱 목록에서 제거한 뒤 반경 진입 → 알림 발생
[ ] 기기 재부팅 후 → 모니터링 자동 복구
[ ] 블루투스 이어폰 연결 → 소리가 이어폰으로만
[ ] 블루투스 해제 → 진동만, 스피커 무음
[ ] 알림 도중 이어폰을 뽑음 → 스피커로 새지 않음
[ ] 해제 버튼 → 즉시 정지 (비행기 모드에서도)
[ ] 3분 내 재알림 → 전면광고 미노출
[ ] 반경 경계에서 5분 대기 → 알림 중복 없음
[ ] 지하철·지하 주차장 통과 → 오작동 없음
[ ] 시스템 글자 크기 최대 → 알림 화면 정상
[ ] 권한 전부 거부 → 앱이 죽지 않고 안내 표시
[ ] 절전 모드 · 배터리 최적화 켠 상태 → 서비스 생존
```

**"알림 도중 이어폰을 뽑음"** 항목을 빠뜨리기 쉬운데, 실제로 자주 일어나고 스피커로 새기 가장 쉬운 상황이다.
