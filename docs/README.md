## 이 프로젝트의 현재 위치

**앱 코드는 아직 없다.** `lib/main.dart` 는 `flutter create` 기본 템플릿이다.

반면 CI/CD 는 거의 완성되어 있다 — Play Store · TestFlight 자동 배포, 버전 자동 증가, CHANGELOG 자동 생성까지 동작한다. 커밋 227개 중 대부분이 이 파이프라인을 만든 기록이다.

즉 **배포할 통로는 뚫려 있고 실어 보낼 물건이 없는 상태다.** 이 문서들은 그 물건의 설계도다.

## 문서 유지 규칙

**설계 판단을 바꿨으면 [10-DECISIONS](10-DECISIONS.md) 에 항목을 추가하고, 해당 문서를 함께 고친다.**

문서와 코드가 어긋나면 문서는 거짓말이 되고, 그 시점부터 아무도 믿지 않게 된다. 이 프로젝트는 개발자 1인이 단독으로 만들고 유지한다. 6개월 뒤의 자신이 유일한 독자다.

[01-REQUIREMENTS](01-REQUIREMENTS.md) 는 **만들 것의 범위**다. 여기 없는 기능은 만들지 않는다. 범위를 늘리려면 문서를 먼저 고친다.

## 출처

기능 명세의 원본은 [GitHub 이슈 #1](https://github.com/Cassiiopeia/EarLocAlert/issues/1) 이다. 본문과 댓글 5개에 개요·기능명세·아키텍처·화면설계·로드맵·소개서가 흩어져 있다.

이 문서들은 그 내용을 옮겨온 것이지만, **그대로 옮기지 않았다.** 원 명세에는 iOS 에서 물리적으로 불가능한 항목이 여럿 있어 기술 검증을 거쳐 판정했다. 무엇을 왜 깎았는지는 [10-DECISIONS](10-DECISIONS.md) 에 있다.
