# EarLocAlert art guide

> Read by the agent before every image request. Keep it short and concrete.

## Look
- Medium and style: clean flat vector with soft neon glow, rounded geometric shapes, minimal detail (like assets/icon/app_icon.png)
- Line and shading: no outlines or very thin; soft gradients and a gentle mint glow on key objects
- Palette: mint #6FE3D3 (main glow), deep teal #0A7A6D, white #FFFFFF, soft gray #98989F, dark navy #0B1622 for shapes; low saturation elsewhere
- Lighting: soft glow from the mint elements, no harsh shadows

## Reference images
- ../../assets/icon/app_icon.png (원본 그대로 참조): style and palette (pin + earbud, mint glow on navy)

## Layout rules for this app
- Onboarding scenes: transparent background, subject centered, 12% empty margin, must read on both black (#000000) and light gray (#F2F2F7)
- Keep shapes simple enough to read at 200dp wide

## Never
- Text, logos, watermarks, signatures, frames, UI text
- Photo-real or busy scenes
- Drawing with code (SVG, PIL, canvas). Images come from the image model only
