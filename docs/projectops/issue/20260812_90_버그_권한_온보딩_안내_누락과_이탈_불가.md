🗒️ 설명
---

권한 온보딩이 두 방향으로 동시에 잘못 동작한다. **물어봐야 할 것을 안 묻고, 넘어갈 수 있어야 할 곳에서 가둔다.**

**① 알림 신뢰성 권한 안내가 뜨지 않는다**

배터리 최적화 예외, 다른 앱 위에 표시, 전체화면 알림을 안내하는 단계(#74에서 추가)가 화면에 나타나지 않고 곧바로 홈으로 진입한다.

온보딩 화면은 두 가지 비동기 상태를 읽는다. 권한 상태 조회는 끝날 때까지 기다리지만, "신뢰성 권한을 이미 안내했는가"라는 저장값은 **아직 읽지 못했으면 '이미 안내했다'로 간주하고 통과시킨다**. 권한이 이미 허용된 기존 사용자는 권한 조회가 먼저 끝나므로, 저장값 읽기가 늦으면 안내 단계 없이 완료로 판정되어 홈으로 넘어간다.

더 나쁜 점은 **이 경로에서는 "안내했다"는 기록도 남지 않는다**는 것이다. 저장값은 계속 "안내 안 함" 상태로 남고, 다음 실행에서도 같은 일이 반복된다. 결과적으로 해당 안내를 **영영 볼 수 없다**. 홈 화면 하단 배너로 직접 찾아가는 것 외에 경로가 없다.

배터리 최적화 예외가 없으면 절전 상태에서 지오펜스 이벤트가 지연되거나 누락되므로, 사용자는 "알림이 안 울린다"로 겪는다.

**② 권한을 거부하면 온보딩에서 나갈 수 없다**

필수 권한(사용 중 위치, 항상 위치, 알림)이 거부된 상태에서는 "나중에 하기" 버튼이 나타나지 않는다. 현재는 **영구 거부 상태일 때만** 이탈이 허용된다.

iOS는 위치 권한을 한 번 거부하면 두 번째부터 시스템 다이얼로그를 띄우지 않는다. 이 상태에서 사용자는 버튼을 눌러도 아무 일이 일어나지 않는 화면에 갇힌다. **권한을 거부해도 앱 기본 화면까지는 도달할 수 있어야 한다는 App Store 심사 방침과 정면으로 충돌하며, 심사 반려 사유가 될 수 있다.**

**③ 문서와 코드가 어긋나 있다**

`docs/01-REQUIREMENTS.md`의 A-12와 `docs/06-UX.md`는 "권한을 거부해도 앱은 정상적으로 열린다"고 명시하고 있으나, 실제 코드는 거부(재요청 가능) 상태에서 이탈을 막는다. 테스트도 "아직 요청할 것이 남아 있으면 나갈 수 없다"로 현재 동작을 고정하고 있어, 문서가 아니라 코드 쪽 판단이 테스트로 굳어진 상태다.

🔄 재현 방법
---

**① 신뢰성 권한 안내 누락**

1. 이전 버전에서 위치, 항상 위치, 알림 권한을 모두 허용해둔다
2. 배터리 최적화 예외는 허용하지 않은 상태로 둔다
3. 최신 버전으로 업데이트한 뒤 앱을 실행한다
4. 배터리 최적화 안내 화면 없이 홈으로 진입하는 것을 확인한다
5. 앱을 껐다 켜도 같은 안내가 나타나지 않는 것을 확인한다

**② 온보딩 이탈 불가**

1. 앱을 새로 설치하고 실행한다
2. 위치 권한 요청 다이얼로그에서 "허용 안 함"을 선택한다
3. 온보딩 화면에 "나중에 하기" 버튼이 없는 것을 확인한다
4. (iOS) 버튼을 다시 눌러도 시스템 다이얼로그가 뜨지 않아 진행이 불가능한 것을 확인한다

✅ 예상 동작
---

**원칙: 반드시 한 번은 묻는다. 단, 어느 단계에서든 건너뛸 수 있다.**

1. 모든 권한 단계는 **최소 한 번은 화면에 표시**된다. 저장값을 아직 읽지 못한 상태에서 단계를 건너뛰지 않는다. 판정에 필요한 값이 모두 준비된 뒤에 다음 단계를 결정한다.

2. **모든 단계에 "나중에 하기"가 있다.** 필수 권한이든 선택 권한이든, 거부 상태든 미요청 상태든 사용자는 홈으로 진입할 수 있다.

3. 건너뛴 항목은 홈 화면에 **무엇이 안 되는지와 켜러 가는 경로**를 상시 표시한다. 이미 있는 배너를 이 원칙에 맞게 정리한다.

4. "안내했다"는 기록은 **실제로 화면을 보여준 뒤에만** 남긴다. 화면을 건너뛴 경로에서 기록이 남거나, 반대로 안내하고도 기록이 남지 않는 일이 없어야 한다.

5. 읽기 실패나 미확인 상태의 기본값을 **한쪽으로 통일**한다. "모르면 한 번 더 묻는다"를 기본으로 삼는다. 한 번 덜 묻는 쪽을 택한 결과가 지금의 영구 미노출이다.

6. 문서(A-12)와 코드, 테스트가 같은 것을 말하도록 맞춘다. 이탈 허용 범위가 바뀌므로 관련 테스트를 함께 고친다.
