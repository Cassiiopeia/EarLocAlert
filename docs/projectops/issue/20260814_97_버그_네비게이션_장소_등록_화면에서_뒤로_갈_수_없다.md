🗒️ 설명
---

**장소 등록·편집 화면에 들어가면 나올 방법이 없다.**

- 화면 좌상단에 뒤로가기 버튼이 **없다**
- 시스템 뒤로가기(제스처·버튼)를 눌러도 홈으로 가지 않는다
- 등록을 완료하거나 앱을 강제 종료하는 것 외에 빠져나올 길이 없다

같은 문제가 진단 기록 화면에도 있다.

### 원인

`lib/app/router.dart` 에서 화면 전환에 `context.go` 를 쓰고 있다.

```dart
onAddPlace: () => context.go(AppRoutes.placeNew),
onEditPlace: (place) => context.go(AppRoutes.placeEdit, extra: place),
onOpenDiagnostics: () => context.go(AppRoutes.diagnostics),
```

**`go` 는 라우트 스택을 교체한다.** 이전 화면이 스택에서 사라지므로

- `AppBar` 가 자동 뒤로가기 버튼을 만들지 않는다 (돌아갈 곳이 없으니 안 만드는 것이 정상 동작이다)
- 시스템 뒤로가기도 pop 할 대상이 없다

반면 지도 선택 화면은 `context.push` 를 쓰고 있어(`router.dart:115`) 뒤로가기가 정상 동작한다. **같은 파일 안에서 두 방식이 섞여 있었고, 그 차이가 그대로 사용자에게 드러났다.**

🔄 재현 방법
---

1. 홈 화면에서 `+` 버튼을 누른다
2. 장소 등록 화면이 열린다
3. 좌상단에 뒤로가기 버튼이 없음을 확인한다
4. 시스템 뒤로가기를 눌러도 홈으로 가지 않는다

진단 기록 화면(홈 상단 아이콘)도 동일하다.

- `lib/features/places/presentation/place_form_screen.dart` — 장소 등록·편집

✅ 예상 동작
---

- 장소 등록·편집 화면에 **뒤로가기 버튼이 보인다**
- 시스템 뒤로가기로 홈에 돌아간다
- 등록·수정을 완료하면 홈으로 돌아간다 (기존과 동일)
- 진단 기록 화면도 동일하게 동작한다

### 해결 방향

스택에 쌓이는 전환(`context.push`)으로 바꾼다. 그러면 뒤로가기 버튼이 자동으로 생기고 시스템 뒤로가기도 동작한다.

저장 완료 시에는 pop 으로 돌아가되, **딥링크 등으로 스택 없이 진입한 경우를 대비해** `canPop()` 을 확인하고 아니면 홈으로 보낸다. 확인하지 않으면 그 경로에서 다시 갇힌다.
