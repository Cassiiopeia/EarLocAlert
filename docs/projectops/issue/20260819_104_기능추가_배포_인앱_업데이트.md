📝 현재 문제점
---

**새 버전이 나와도 앱 안에서 알 방법이 없다.** 지금은 GitHub 릴리스 페이지를 직접 열어 APK 링크를 찾아 내려받고 설치해야 한다.

```
https://github.com/Cassiiopeia/EarLocAlert/releases/download/v1.7.2/EarLocAlert-v1.7.2-34050c2.apk
```

실기기 검증을 반복하는 지금 단계에서 이 왕복이 매번 발생한다. 스토어 배포 전까지는 사이드로드가 유일한 배포 경로라 앱이 스스로 최신 버전을 알려주는 것이 맞다.

🛠️ 해결 방안 / 제안 기능
---

설정 화면에 **버전 정보와 업데이트 확인** 항목을 둔다.

- 현재 버전을 보여주고, 눌러서 최신 릴리스를 조회한다
- 최신 버전이 더 높으면 릴리스 노트와 함께 내려받기를 제안한다
- 받은 APK 로 설치 화면을 띄운다 (설치 자체는 사용자가 확인한다)
- 최신이면 최신이라고만 알린다

조회는 GitHub 공개 릴리스 API 를 쓴다. 공개 레포라 토큰이 필요 없다.

**전제와 경계**

- 자동 설치는 하지 않는다. 앱이 하는 것은 내려받기와 설치 화면 호출까지다
- 앱 설치 권한은 사용자가 허용해야 한다. 거부해도 앱은 정상 동작한다
- 네트워크는 지금도 광고에만 쓰고 위치는 전송하지 않는다. 이 기능도 릴리스 정보 조회와 APK 내려받기 외에 아무것도 보내지 않는다
- **iOS 에는 없다.** 사이드로드 경로가 없으므로 Android 전용이다
- 스토어 배포가 시작되면 이 경로는 걷어낸다
