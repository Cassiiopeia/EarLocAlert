🗒️ 설명
---

**진단 기록 화면이 항상 "0건"으로 뜬다.** 장소를 여러 개 등록하고 앱을 쓰는 중인데도 "아직 기록이 없습니다"만 나온다.

**파일에는 기록이 쌓이고 있다.** 에뮬레이터에서 확인한 실제 파일:

```
2026-08-19T23:44:38.656350Z [engine] 감시 엔진 시작
2026-08-19T23:44:38.740Z [registrar] 지오펜스 등록 성공 2개 (장소 1곳)
2026-08-19T23:44:38.746Z [watch] 네이티브 지오펜스 등록 1건 (요청 1건)
```

원인은 **화면이 파일을 직접 읽지 않고 전역 로거를 거치기** 때문이다.

```dart
final content = await Diagnostics.logger.readAll();
```

`Diagnostics.logger` 는 앱 시작 시 `init()` 이 성공해야 파일 로거가 된다. 실패하면 아무것도 하지 않는 로거로 남고, 그 `readAll()` 은 **무조건 빈 문자열**이다.

특히 Kotlin 계층은 Dart 초기화와 무관하게 파일에 직접 쓴다. 그래서 `[watch]`·`[registrar]` 기록이 잔뜩 있어도 화면에서는 통째로 사라진다.

**진단 화면이 진단 대상의 초기화 성공에 의존하고 있었다** — 정확히 그것이 실패했을 때 열리는 화면인데.

🔄 재현 방법
---

1. 장소를 등록하고 앱을 사용한다
2. 설정 → 진단 기록을 연다
3. 기록이 쌓여 있어야 하는데 "0건 / 아직 기록이 없습니다"가 뜬다

📸 참고 자료
---

- `lib/features/diagnostics/presentation/diagnostics_screen.dart` — `_load()`
- `lib/core/diagnostics/diagnostics.dart` — `init()` 실패 시 Noop 유지
- `lib/core/diagnostics/diagnostic_logger.dart` — `NoopDiagnosticLogger.readAll()` 이 빈 문자열

**테스트가 이것을 잡지 못했다.** 로거 단위 테스트(`file_diagnostic_logger_test.dart`)는 있었으나 **화면이 실제로 무엇을 읽는지 확인하는 테스트가 없었다.**

**남는 기록도 부족하다.** 알림 발화·오디오 판정·권한 상태·장소 변경·앱 생명주기에 로그가 없어, 기록을 읽어도 "그때 무슨 일이 있었는지" 재구성되지 않는다. 이 앱은 백그라운드 동작이 핵심이라 재현이 안 되고, 남은 기록이 유일한 단서다.

✅ 예상 동작
---

- 진단 화면이 **파일을 직접 읽는다.** 전역 로거 초기화 성공 여부와 무관하다
- **"기록 없음"과 "읽지 못함"을 구분해서 보여준다.** 못 읽는 중에 "기록이 없습니다"를 보면 사용자는 감시가 안 도는 줄 알고 없는 문제를 찾게 된다
- 알림 경로 전반에 기록이 남아 사후에 원인을 가릴 수 있다
- 화면을 열었다는 사실 자체가 기록에 남아, 로깅이 살아있는지 사용자가 스스로 확인할 수 있다
