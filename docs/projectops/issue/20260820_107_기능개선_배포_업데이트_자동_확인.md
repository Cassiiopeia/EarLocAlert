📝 현재 문제점
---

업데이트 확인이 **설정 화면에 들어가 직접 눌러야만** 동작한다 (#104). 새 버전이 나와도 사용자가 그 자리를 찾아 들어가지 않으면 영영 모른다.

실기기 검증을 반복하는 지금 단계에서는 새 버전이 자주 나오는데, 매번 "설정 → 업데이트 확인"을 눌러 확인해야 한다.

🛠️ 해결 방안 / 제안 기능
---

앱이 **하루 한 번 스스로 확인**하고, 새 버전이 있으면 홈 화면에 알린다.

```
앱이 앞으로 나옴
  → 마지막 확인이 24시간 지났나?
      아니오 → 아무것도 하지 않는다
      예     → 조용히 조회 (화면을 막지 않는다)
          → 새 버전 있나?
              없음 → 확인 시각만 기록
              있음 → 홈 상단에 배너
                        → 누르면 지금 있는 업데이트 화면이 열린다
```

**하루 한 번인 이유** — 앱을 켤 때마다 조회하면 GitHub 요청 한도(인증 없이 IP당 시간당 60회)를 낭비한다. 한도가 차면 그때부터 확인이 조용히 실패한다. 새 버전이 하루에 두 번 나오지 않으므로 24시간이면 충분하다.

**다이얼로그를 쓰지 않는 이유** — 앱 켤 때마다 뭔가 튀어나오면 방해다. 특히 **알림이 울리는 중에 업데이트 다이얼로그가 뜨면 최악이다.** 급하게 진동을 끄려는데 다른 것이 떠 있는 상황이 된다. 홈 상단에는 이미 "알림이 약합니다" 배너 자리가 있고, 알림 화면은 별도 화면이라 겹치지 않는다.

**실패를 알리지 않는 이유** — 지하철에서 앱을 켰는데 "업데이트 확인 실패"가 뜨면 그건 방해다. 사용자가 직접 눌렀을 때만 실패 사유를 보여준다.

**"이 버전 건너뛰기"가 필요하다** — 없으면 업데이트를 미루는 사용자가 매일 같은 배너를 본다. 한 번 건너뛰면 그 버전은 다시 알리지 않는다.

⚙️ 작업 내용
---

- 확인 주기 판정 (마지막 확인 시각, 건너뛴 버전) — 순수 로직으로 두어 테스트한다
- 홈 배너와 진입 경로
- 알림 세션이 살아있는 동안에는 배너를 띄우지 않는다

**받는 것까지 자동으로 하지 않는다.** APK 가 60MB 라 셀룰러에서 자동으로 받으면 데이터가 나간다. 배너를 눌렀을 때 받는다.

**설치 자동화는 불가능하다.** 무음 설치는 `INSTALL_PACKAGES` 권한이 필요한데 시스템 앱에만 부여된다. 기기 소유자(Device Owner) 앱은 예외지만 기업 관리용이라 개인 기기에 쓸 수 없다. **설치 확인 한 번은 Android 정책상 줄일 수 없다.**
