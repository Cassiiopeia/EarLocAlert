📝 현재 문제점
---

Play 스토어 심사 제출을 앞두고 현재 상태를 점검했다. **반려로 직결되는 항목이 다섯 개 있다.**

**1. `REQUEST_INSTALL_PACKAGES` 권한 (가장 위험)**

인앱 업데이트(#104)를 위해 선언했다. Play 는 이 권한을 앱스토어, 파일 관리자 같은 핵심 기능이 아니면 거의 반려한다. 위치 알림 앱이 다른 앱을 설치할 이유는 설명할 수 없다.

**다만 실기기 검증이 끝날 때까지는 이 기능이 필요하다.** 새 버전을 받을 다른 경로가 사이드로드뿐이라, 지금 걷어내면 검증 때마다 APK 를 수동으로 내려받아야 한다.

**2. AdMob 앱 ID 가 Google 공개 테스트 ID 다**

```
AndroidManifest.xml:104   ca-app-pub-3940256099942544~3347511713
ios/Runner/Info.plist:37  ca-app-pub-3940256099942544~1458002511
```

광고 **단위** ID 는 빌드별로 분기되는데(`AdUnitIds`), **앱 ID 는 하드코딩이라 릴리스에서도 테스트 값이 나간다.** 이 상태로 출시하면 앱 ID 와 광고 단위가 불일치해 광고가 아예 안 나오고, 테스트 앱 ID 로 프로덕션 출시하는 것 자체가 AdMob 정책에 어긋난다.

**3. 개인정보 처리방침 URL 없음** — Play Console 필수 항목이라 제출 자체가 불가능하다.

**4. 백그라운드 위치 시연 영상 미제작** — `ACCESS_BACKGROUND_LOCATION` 은 별도 선언 양식과 기능 시연 영상을 요구한다. 반려율이 높고 재심사에 시간이 걸린다.

**5. 데이터 보안 양식 미작성** — `AD_ID` 수집 신고가 필요하다.

🛠️ 해결 방안 / 제안 기능
---

### 먼저: 인앱 업데이트를 플래그로 끄고 켠다

기능을 지금 지우지 않고 **`.env` 의 `DEV_FLAG` 한 줄로 통째로 빼고 넣을 수 있게** 만든다. 검증 중에는 켜고, 심사 빌드에서는 끈다.

**Dart 기능만 숨기는 것으로는 부족하다.** 권한 선언이 매니페스트에 남아 있으면 심사에 그대로 걸린다. 플래그가 꺼지면 **권한과 FileProvider 선언까지 함께 빠져야** 의미가 있다.

Maps 키와 같은 경로를 쓴다 — `.env` 가 단일 소스이고 gradle 이 읽어 네이티브에 주입한다.

| 플래그 | 인앱 업데이트 | `REQUEST_INSTALL_PACKAGES` | FileProvider |
|---|---|---|---|
| `DEV_FLAG=true` | 설정에 표시 | 선언됨 | 선언됨 |
| `DEV_FLAG=false` 또는 없음 | 숨김 | **빠짐** | **빠짐** |

**기본값은 꺼짐이다.** `.env` 가 없는 사람이 빌드하면 심사 가능한 형태로 나오는 것이 안전하다.

### 그다음: 심사 제출 항목

- AdMob 앱 등록 후 실제 앱 ID 를 `.env` 로 주입 (Maps 키와 같은 방식)
- 개인정보 처리방침 작성, 호스팅 (한/영)
- 백그라운드 위치 시연 영상 촬영 — **앱을 완전히 종료한 상태에서 이동해 알림이 뜨는 장면**이 핵심이다
- 데이터 보안 양식, 권한 선언, 콘텐츠 등급

### 설명이 필요하나 사유가 준비된 권한

`SYSTEM_ALERT_WINDOW`, `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`, `USE_FULL_SCREEN_INTENT`, `FOREGROUND_SERVICE_LOCATION` 은 사유서가 이미 있다. **셋 다 거부돼도 앱이 동작한다는 점을 함께 밝히는 것이 가장 유리한 논거**이고, 실제로 그렇게 만들어져 있다.

`USE_FULL_SCREEN_INTENT` 는 Android 14+ 에서 Play Console 별도 선언이 필요하다.

### 문제 없는 것

targetSdk 36(Android 16), 패키지명·앱 이름 확정, 광고 단위 ID 분기 로직, 알림 화면에 광고를 겹치지 않는 구조.

⚙️ 작업 내용
---

- `.env` 의 `DEV_FLAG` 를 gradle 이 읽어 매니페스트 병합과 BuildConfig 에 반영
- 플래그가 꺼지면 설정 화면에서 업데이트 항목이 사라진다
- 개인정보 처리방침 초안
- 심사 제출 문구 정리
