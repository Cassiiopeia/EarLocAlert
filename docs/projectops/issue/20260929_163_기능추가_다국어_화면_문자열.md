📝 현재 문제점
---

- 이 앱은 한국에서만 쓸 수 있다. **화면 문자열이 전부 한국어로 코드에 박혀 있어서**, 기기 언어가 영어여도 한국어로 뜬다. 앱을 한국 밖에서도 쓸 수 있어야 한다.
- 문서(`docs/04-CONVENTIONS.md`, `CLAUDE.md`)는 "MVP 는 한국어만 내되 **문자열은 처음부터 하드코딩하지 않는다**(`context.l10n.xxx`)"고 적고, `docs/01-REQUIREMENTS.md` F5 는 다국어(한국어, 영어)를 Phase 2 로 두었다. **그러나 코드에는 l10n 이 전혀 없다.**

**조사 결과 (2026-09-29)**

| 항목 | 상태 |
|---|---|
| ARB 파일, `l10n.yaml`, `flutter_localizations`, `intl` 의존성 | **없음** |
| `MaterialApp` 의 `supportedLocales`, `localizationsDelegates` | 지정 안 됨 (기기 언어를 따르는 장치가 없다) |
| 한글이 들어 있는 Dart 파일 | 147개 (생성 파일 제외) |
| 화면 문자열 후보 | 주석과 로그 호출을 뺀 근사치로 약 300줄. 많은 순: 지도 홈 화면, 장소 등록 폼, 백그라운드 판정 처리기, 알림 컨트롤러, 라우터, 지도 선택 화면, 알림 화면, 알림음 서비스 |
| 단위와 시간 표기 | `m`, `km/h`, `분`, 요일 이름, `N곳` 같은 표기가 문자열 안에 직접 들어 있음 |

**기기 언어를 따르도록 만들려면 문자열을 옮기는 것 말고도 정해야 할 것이 있다.**

🛠️ 해결 방안 / 제안 기능
---

**정책 (제안, 확정 필요)**
- 지원 언어는 **한국어와 영어** 둘로 시작한다. 이후 언어는 같은 구조로 파일만 추가하면 되게 한다.
- **기기 언어가 한국어이면 한국어, 그 외 모든 언어는 영어**로 보인다(기본 언어는 영어).
- 앱 안에서 언어를 따로 고르는 설정은 이번 범위에 넣지 않는다. Android 13+ 의 앱별 언어 설정이 동작하도록 지원 언어 목록을 OS 에 알리는 것까지만 본다.

**작업 내용**
- 다국어 기반 마련: 한국어 원문을 기준으로 영어 번역 파일을 만들고, 문서가 이미 약속한 `context.l10n.키` 형태로 접근하게 한다. `MaterialApp` 에 지원 언어와 기본(영어) 규칙을 건다.
- 모든 화면 문자열 이전: 온보딩, 지도 홈, 장소 등록/편집 폼, 알림 화면, 설정, 진단 화면, 광고 후 화면, 오류·안내 문구, 알림음 이름과 상태 문구, 백그라운드에서 Dart 가 만드는 알림 문구.
- **표기 규칙 통일**: 거리(`m`, `km`), 시간(시간대 창), 요일 이름, 개수(`N곳`)를 언어별 규칙(복수형, 순서)에 맞게 만든다. 문자열을 이어 붙여 문장을 만드는 곳은 통째로 번역 단위로 바꾼다.
- **글자 길이**: 영어가 한국어보다 길어지는 곳(버튼, 칩, 알림 화면의 84px 해제 버튼, 상태 알약, 두 줄 장소명 + 지도 카드 조합)에서 넘치지 않는지 확인한다. 이전에 Pretendard 도입 때 29px 넘침을 찾은 자리다(#145).
- **규칙을 테스트가 지키게 한다**(결정 035 방식): 로그 호출을 뺀 Dart 코드에 한글 문자열 리터럴이 새로 생기면 테스트가 실패하게 한다.
- 문서 바로잡기: `CLAUDE.md` 와 `docs/04-CONVENTIONS.md` 의 "l10n 을 거친다"가 실제와 맞도록 갱신하고, `docs/10-DECISIONS.md` 에 결정(지원 언어, 기본 언어 규칙)을 남긴다.

**이 이슈에 넣지 않는 것**
- 네이티브(Kotlin, iOS) 문자열 → 별도 이슈
- 진단 로그 → 별도 이슈
- 스토어 등록정보, 앱 이름, 한국 전제 제거 → 별도 이슈
- 오른쪽에서 왼쪽으로 쓰는 언어(RTL), 3번째 이후 언어

**완료 기준**
- 기기 언어를 영어로 바꾸면 모든 화면이 영어로 보이고, 한국어이면 지금과 같다. 지원하지 않는 언어(예: 일본어)는 영어로 보인다.
- 두 언어 모두에서 텍스트가 넘치거나 잘리는 화면이 없다.
- 한글 하드코딩이 새로 들어오면 테스트가 실패한다.
