📝 현재 문제점
---

- 이 앱은 한국에서만 쓸 수 있다. **화면 문자열이 전부 한국어로 코드에 박혀 있어서**, 기기 언어가 영어여도 한국어로 뜬다. 앱을 한국 밖에서도 쓸 수 있어야 한다.
- 문서(`docs/04-CONVENTIONS.md`, `CLAUDE.md`)는 "MVP 는 한국어만 내되 **문자열은 처음부터 하드코딩하지 않는다**(`context.l10n.xxx`)"고 적고, `docs/01-REQUIREMENTS.md` F5 는 다국어를 Phase 2 로 두었다. **그러나 코드에는 l10n 이 전혀 없다.**

**조사 결과 (2026-09-29)**

| 항목 | 상태 |
|---|---|
| ARB 파일, `l10n.yaml`, `flutter_localizations`, `intl` 의존성 | **없음** |
| `MaterialApp` 의 `supportedLocales`, `localizationsDelegates` | 지정 안 됨 (기기 언어를 따르는 장치가 없다) |
| 한글이 들어 있는 Dart 파일 | 147개 (생성 파일 제외) |
| 화면 문자열 후보 | 주석과 로그 호출을 뺀 근사치로 약 300줄. 많은 순: 지도 홈 화면, 장소 등록 폼, 백그라운드 판정 처리기, 알림 컨트롤러, 라우터, 지도 선택 화면, 알림 화면, 알림음 서비스 |
| 단위와 시간 표기 | `m`, `km/h`, `분`, 요일 이름, `N곳` 같은 표기가 문자열 안에 직접 들어 있음 |
| 폰트 | Pretendard(한글과 라틴) 네 굵기만 번들. **일본어와 중국어 글자는 들어 있지 않다** |

🛠️ 해결 방안 / 제안 기능
---

**정책 (확정)**
- 지원 언어는 **한국어, 영어, 중국어, 일본어** 네 가지다. 이후 언어는 같은 구조로 파일만 추가하면 되게 한다.
- **기본값은 기기 설정의 언어**를 따른다. 기기 언어가 지원 목록에 없으면 영어로 보인다.
- **설정 화면에서 앱 언어를 직접 바꿀 수 있어야 한다.** 고른 값은 저장되고 앱을 다시 켜지 않아도 바로 적용되며, 언제든 "기기 설정 따르기"로 되돌릴 수 있다.

**실수로 눌렀을 때도 되돌릴 수 있어야 한다 (핵심 요구)**
- 언어를 잘못 골라 **읽을 수 없는 언어로 바뀌어도 스스로 빠져나올 수 있어야 한다.**
- 설정 안의 언어 항목은 **문구가 아니라 지구본 아이콘으로 알아볼 수 있게** 표시하고, 위치는 언어와 상관없이 항상 같은 자리(설정의 맨 위)에 둔다. 홈에서 설정으로 가는 버튼이 이미 아이콘이라(#155) 진입까지는 언어에 의존하지 않는다.
- 언어 선택 목록은 **각 언어를 그 언어 자신의 표기로 고정해 보여준다**(한국어, English, 中文, 日本語). 번역하지 않는다. 그래야 어느 언어에서 열어도 자기 언어를 찾을 수 있다.
- "기기 설정 따르기" 항목도 아이콘과 함께 목록에 둔다.
- 언어를 바꾸면 되돌리기 안내를 잠깐 보여주는 방안은 구현 중 판단한다(예: 바꾼 직후 몇 초간 "되돌리기").

**작업 내용**
- 다국어 기반 마련: 한국어 원문을 기준으로 영어, 중국어, 일본어 번역 파일을 만들고, 문서가 이미 약속한 `context.l10n.키` 형태로 접근하게 한다. `MaterialApp` 에 지원 언어, 기본(영어) 규칙, **사용자가 고른 언어가 기기 언어보다 우선하는 규칙**을 건다.
- **선택한 언어 저장**: 기기에 저장하고 앱이 뜰 때 읽는다. 백그라운드 진입점(Dart 알림 문구를 만드는 곳)과 네이티브도 같은 값을 읽어야 한다(#164 와 연결).
- 모든 화면 문자열 이전: 온보딩, 지도 홈, 장소 등록/편집 폼, 알림 화면, 설정, 진단 화면, 광고 후 화면, 오류와 안내 문구, 알림음 이름과 상태 문구, 백그라운드에서 Dart 가 만드는 알림 문구.
- **표기 규칙 통일**: 거리(`m`, `km`), 시간(시간대 창, 24시간/12시간), 요일 이름, 개수(`N곳`)를 언어별 규칙(복수형, 순서, 조사)에 맞게 만든다. 문자열을 이어 붙여 문장을 만드는 곳은 통째로 번역 단위로 바꾼다.
- **일본어와 중국어 글꼴**: 번들 폰트에 글자가 없어 시스템 글꼴로 대체된다. 글자 모양과 굵기가 어긋나지 않는지 확인하고 방침을 정한다. 일본어와 중국어 글꼴을 번들하면 언어마다 수 MB 가 늘어나므로(현재 폰트 6MB), 시스템 글꼴 대체를 기본으로 두고 어긋남을 보는 것을 권장한다(결정 필요).
- **글자 길이**: 영어는 길어지고 중국어와 일본어는 한 글자 폭이 달라진다. 버튼, 칩, 알림 화면의 84px 해제 버튼, 상태 알약, 두 줄 장소명 + 지도 카드 조합에서 넘치지 않는지 네 언어 모두 확인한다. 이전에 Pretendard 도입 때 29px 넘침을 찾은 자리다(#145).
- **규칙을 테스트가 지키게 한다**(결정 035 방식): 로그 호출을 뺀 Dart 코드에 한글 문자열 리터럴이 새로 생기면 테스트가 실패하게 한다. 네 언어의 번역 키가 서로 빠짐없이 같은지도 테스트로 확인한다.
- 문서 바로잡기: `CLAUDE.md` 와 `docs/04-CONVENTIONS.md` 의 "l10n 을 거친다"가 실제와 맞도록 갱신하고, `docs/10-DECISIONS.md` 에 결정(지원 언어, 기본값 규칙, 언어 복구 방식, 글꼴 방침)을 남긴다.

**기존 명세와 부딪히는 것 (설계 명세 `docs/superpowers/specs/2026-09-29-i18n-design.md` §3 에 전체 목록과 해결)**

| 부딪히는 것 | 왜 깨지나 |
|---|---|
| 결정 037 `keepAll` | 모든 글자 사이에 줄바꿈 금지 문자를 넣어서 띄어쓰기가 없는 중국어와 일본어는 **줄이 안 바뀌어 넘친다.** 한국어에만 적용하도록 바꿔야 한다 |
| 결정 035 `design_system_test` | 소스의 한글 리터럴을 센다. 문자열이 번역 파일로 옮겨지면 **규칙이 조용히 무력화된다** |
| 한글 문구를 찾는 위젯 테스트 | 11개 파일 54곳이 언어가 바뀌면 깨진다 |
| 프로젝트 규칙 6 (백그라운드에서 `BuildContext` 금지) | 문서의 `context.l10n` 을 백그라운드 알림 문구(`BackgroundAlertNotifier`)에 쓸 수 없다. **컨텍스트 없이 언어로 문구를 찾는 경로가 따로 필요**하다 |
| 백그라운드 isolate | 앱에서 바꾼 언어를 다시 읽지 않으면 옛 언어로 알림을 만든다 |
| 프로젝트 규칙 4 (feature 끼리 import 금지) | 언어 값과 번역은 `core` 에 두고 `app` 계층이 주입한다 |

**설계 단계에서 정해야 할 것 (권장안은 명세 §4)**: 중국어 간체/번체, 언어 저장 위치와 네이티브와의 계약, OS 앱별 언어 기능과의 관계, 울리는 중 언어 변경, 지도 라벨 언어, 글꼴, 날짜와 시간 표기, 번역 검수 방식.

**확인이 필요한 것**
- **중국어 표기**: 간체(중국 본토)만 할지, 번체(대만, 홍콩)도 지원할지 정해야 한다. 간체로 시작하고, 번체 기기는 우선 간체가 아닌 영어로 보이게 둘지 정한다.

**완료 기준**
- 기기 언어가 네 언어 중 하나이면 처음부터 그 언어로 보이고, 아니면 영어로 보인다.
- 설정에서 언어를 바꾸면 앱을 다시 켜지 않고 바로 적용되고, 다시 켜도 유지된다. "기기 설정 따르기"로 되돌릴 수 있다.
- **읽을 수 없는 언어로 바꿨을 때** 아이콘과 고정된 위치, 각 언어 자기 표기 목록만으로 원래 언어를 찾아 되돌릴 수 있다(네 언어 모두에서 확인).
- 네 언어 모두에서 텍스트가 넘치거나 잘리는 화면이 없다.
- 한글 하드코딩이 새로 들어오면 테스트가 실패한다.
