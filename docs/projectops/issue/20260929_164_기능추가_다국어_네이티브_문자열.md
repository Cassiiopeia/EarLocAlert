📝 현재 문제점
---

- 화면 문자열을 다국어화(#163)해도, **네이티브가 만드는 문자열은 Flutter 의 번역을 쓸 수 없다.** 알림은 앱이 죽어 있을 때 Kotlin 이 직접 만들기 때문이다. 기기가 영어여도 상태바 알림, 설정의 알림 채널 이름, 앱 이름, iOS 권한 안내가 한국어로 남는다.

**조사 결과 (2026-09-29)**

| 위치 | 한국어로 박힌 것 |
|---|---|
| `AlertWatchService.kt` | 감시 상시 알림의 제목과 내용("위치를 지켜보고 있습니다" 등), 알림 채널 이름과 설명("위치 감시" 등), 도착·출발 알림 채널, 끄기 버튼, 이름이 없을 때의 기본 문구("위치 알림") |
| Kotlin 전체 | 한글이 든 문자열 리터럴 약 77개(주석 제외). 그중 진단 로그가 약 38개이고 나머지가 사용자에게 보이거나 로그가 섞인 문자열 |
| `AndroidManifest.xml` | 앱 표시 이름 `android:label="이어폰위치알림"` 고정. `res/values` 에 `strings.xml` 이 아예 없다 |
| `ios/Runner/Info.plist` | 위치(사용 중, 항상 2건), 광고 추적 안내 문구 4건이 한국어로 고정. 앱 표시 이름도 한국어 고정 |
| iOS 지역화 리소스 | `Base.lproj` 만 있고 언어별 `InfoPlist.strings` 없음 |

🛠️ 해결 방안 / 제안 기능
---

**정책**: #163 과 같은 규칙을 쓴다. 지원 언어는 한국어, 영어, 중국어, 일본어이고, **기본값은 기기 언어, 앱 설정에서 고른 언어가 있으면 그것이 우선**한다. 기기 언어가 지원 목록에 없으면 영어.

**작업 내용**
- **Android**: 사용자에게 보이는 문자열을 리소스 파일로 옮기고(기본은 영어, 한국어, 중국어, 일본어는 언어별 폴더), Kotlin 은 리소스에서 읽는다. 앱 표시 이름도 리소스로 옮긴다. 지원 언어 목록을 OS 에 알려 앱별 언어 설정이 동작하게 한다.
- **함정 — 알림 채널 이름은 OS 가 생성 시점에 굳힌다.** 기기 언어나 앱 언어를 바꿔도 이미 만들어진 채널의 이름과 설명은 그대로 남는다. 같은 아이디로 채널을 다시 만들면 이름과 설명은 갱신되므로, 서비스가 뜰 때마다 현재 언어로 갱신하는 처리가 필요하다(진동과 소리 설정은 그대로 유지되어 채널 규칙, 결정 025 에 영향 없음 확인 필요).
- **iOS**: 권한 안내 문구와 앱 표시 이름을 네 언어의 `InfoPlist.strings` 로 옮긴다. 이 문구는 OS 가 **기기 언어**로 고르므로 앱 안에서 고른 언어를 따르게 할 수 없다. 이 한계를 문서에 남기고, 앱 안 문구와 어긋날 수 있음을 인지한다.
- **앱 안에서 고른 언어를 네이티브가 알아야 한다 (핵심).** 알림은 앱이 죽어 있어도 Kotlin 이 만든다. 사용자가 설정에서 기기 언어와 다른 언어를 골랐다면 알림도 그 언어여야 한다. 고른 언어를 네이티브가 읽는 곳에 저장하거나, Android 13 이상의 앱별 언어 기능으로 OS 에 맡기는 방안이 있다. **13 미만 기기에서는 직접 처리해야 하므로 방안을 비교해 정한다.**
- **문구 원본을 하나로 관리**: Dart 화면 문구와 네이티브 문구가 같은 뜻인데 표현이 갈리기 쉽다. 같은 뜻의 문구는 표현을 맞추고, 어느 쪽이 원본인지 문서에 남긴다.
- **소리는 여전히 내지 않는다**: 알림 문구만 바뀌며 채널은 계속 무음이다(프로젝트 규칙 2).

**설계 명세(`docs/superpowers/specs/2026-09-29-i18n-design.md`)에서 정한 방향**
- 앱에서 고른 언어를 저장하는 키는 **앱과 네이티브의 계약**이다(값: `system`, `ko`, `en`, `zh`, `ja`). 키 이름을 문서에 못 박고 양쪽에서 같은 이름을 쓴다.
- Android 13+ 의 OS 앱별 언어 기능은 **선언하지 않는다.** OS 설정 화면에서 앱 언어를 바꿀 수 있게 되면 앱 설정과 두 곳에서 어긋난다. 앱 안 설정을 단일 출처로 둔다.
- 울리고 있는 알림 세션은 언어 변경의 영향을 받지 않는다. 다음 알림부터 새 언어다.
- iOS 권한 안내는 OS 가 기기 언어로 고르므로 앱 안 언어와 어긋날 수 있다. 이 한계를 문서에 남긴다.

**완료 기준**
- 기기 언어를 네 언어 중 하나로 바꾸면 상태바 알림, 설정의 알림 채널 이름, 런처의 앱 이름, iOS 권한 다이얼로그가 그 언어로 보인다. 지원하지 않는 언어이면 영어로 보인다.
- **앱 설정에서 기기와 다른 언어를 골랐을 때** 상태바 알림과 알림 채널 이름이 앱에서 고른 언어로 나온다(앱이 죽어 있는 상태에서 도착 알림을 받아 확인).
- **이미 설치된 앱에서 언어를 바꾼 뒤에도** 알림 채널 이름이 바뀐 언어로 갱신된다.
