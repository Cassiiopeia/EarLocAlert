🛠️ 해결 방안 / 제안 기능
---

**작업 내용 (제안, 우선순위 순)**
1. **광고 동의 확인과 구현**: 실제로 없는지 먼저 확인한다. 없다면 유럽 경제 지역과 영국에서 광고를 띄우기 전에 동의를 받는다. **동의가 없거나 거부돼도 알림 해제는 즉시 끝난다**는 프로젝트 규칙 1 과 3(광고 규칙)은 그대로 지킨다. 심사와 계정 정지에 직결되므로 다국어보다 먼저 볼 항목이다.
2. **기본 지도 위치**: 서울 고정을 없앤다. 기기 위치, 마지막으로 알려진 위치, 기기 지역 순으로 정하고, 모두 없을 때만 중립 위치를 쓴다. 세 곳의 중복도 하나로 모은다.
3. **스토어 등록정보 영어 버전**: 앱 이름, 짧은 설명, 긴 설명, 스크린샷, 권한 사용 설명(백그라운드 위치 시연 영상 포함). 앱 표시 이름을 확정한다(현재 "이어폰위치알림", 영문 "EarLocAlert").
4. **개인정보 처리방침과 소개 페이지 영어 버전**.
5. **주소 검색 제공자 결정**: 해외에서도 되는 제공자를 쓸지, 국내/해외 분기를 둘지 결정 문서에 남긴다(구현은 Phase 2).
6. **시각 표기**: 시간대 창의 시각을 기기 설정(24시간/12시간)에 맞춘다.

**완료 기준**
- 유럽 경제 지역 조건에서 광고 동의가 동작하고, 동의 여부와 무관하게 해제가 즉시 끝난다(테스트로 고정).
- 위치를 못 얻는 상태에서 지도를 열어도 서울로 시작하지 않는다.
- 스토어 등록정보와 처리방침에 영어 버전이 있다.

**이 이슈는 확인과 결정이 많다.** 각 항목을 하위 작업으로 나눠 진행하고, 광고 동의는 먼저 사실 확인부터 한다.
