📝 현재 문제점
---

코드 정리 중 발견했다(이슈 #173 조사). **`AdFrequencyStore.markLaunched()` 를 호출하는 곳이 앱 어디에도 없다.**

- `PrefsAdFrequencyStore.load()` 는 `isFirstLaunch: !(prefs.getBool(_keyLaunched) ?? false)` 로 읽는다
- `_keyLaunched` 를 쓰는 곳은 `markLaunched()` 뿐이고, 호출이 0건이다(정의·구현·테스트 가짜 클래스에만 있다)
- 그래서 `isFirstLaunch` 는 **영원히 true** 이고, `AdFrequencyPolicy` 의 `if (isFirstLaunch) return false;` 때문에 **전면광고가 한 번도 나오지 않는다**

지금은 AdMob 앱 미등록으로 테스트 ID 이고 수익이 없어서 드러나지 않았을 뿐이다. 광고를 실제로 켜는 시점에 수익이 0 으로 나온다.

🛠️ 해결 방안 / 제안 기능
---

**먼저 정책 의도를 정해야 한다** (그래서 이번 정리에 섞지 않았다).
- "첫 실행에는 광고를 보이지 않는다" 라면, **첫 세션이 끝나거나 첫 알림을 해제한 시점에** `markLaunched()` 를 호출해야 다음부터 나온다. 앱 시작에 바로 호출하면 첫 세션의 알림부터 광고가 나온다
- 호출 위치는 알림 해제 뒤(광고 자리)가 자연스럽다. **광고를 기다렸다 해제하지 않는 규칙**(CLAUDE.md 규칙 1)은 그대로 지킨다
- 회귀 테스트: 첫 실행에는 안 나오고, 표시 표식 이후에는 빈도 정책대로 나오는지

같은 조사에서 나온 참고: 로그 90일 보존 정책(`RetentionPolicy`, `deleteOlderThan`)도 정의만 있고 실행하는 곳이 없다.
