### 📝 현재 문제점

- 스마트워치(갤럭시 워치·Apple Watch)를 차고 있어도 알림이 워치로 오지 않는다. 원인은 앱이 아니라 워치 쪽 앱 알림 토글이 꺼져 있어서인데, 사용자가 알 방법이 없다.
- 갤럭시 워치는 새 앱이 기본으로 꺼져 있어 직접 켜야 하고, 켜는 위치가 폰의 앱 설정이 아니라 Galaxy Wearable 앱이다.

### 🛠️ 해결 방안

- 설정 화면 알림 묶음에 "워치로 알림 받기" 항목을 두고, 누르면 바텀시트로 안내를 보여준다.
- 안내는 플랫폼별로 다르게 보여준다.
  - Android: Galaxy Wearable 앱 → 워치 설정 → 알림 → 앱 알림에서 이 앱을 켠다.
  - iOS: iPhone 의 Watch 앱 → 알림에서 이 앱을 켠다.
- 첫 장소를 등록한 직후 같은 안내를 한 번만 띄운다. 닫으면 다시 띄우지 않는다.
- 워치 연결 감지는 하지 않는다(라이브러리·권한 추가 없음). 네 언어(ko/en/ja/zh)로 제공한다.
