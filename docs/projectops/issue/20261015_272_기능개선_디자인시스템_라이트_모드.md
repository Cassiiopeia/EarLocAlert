### 📝 현재 문제점

- 앱이 다크 모드만 지원하고, 화면마다 색·글자 스타일을 직접 박아 둬서 라이트 모드를 더할 수 없다(글자 스타일에 흰색이 고정).
- 전체적인 결이 정리되지 않아 화면이 투박하다. 도착/출발/둘 다 선택처럼 기본 위젯 모양이 그대로 드러난 곳이 있다.

### 🛠️ 해결 방안

- Apple(iOS HIG) 결로 디자인 시스템을 재정립한다. 설계: `docs/superpowers/specs/2026-10-15-design-system-light-dark-design.md`
- 라이트·다크 팔레트 두 벌을 두고, 설정에서 화면 모드(기기 설정 따르기 / 라이트 / 다크)를 고를 수 있게 한다.
- 주색을 민트로 바꾸고 금색은 출발·경고 색으로 둔다.
- 그룹형 목록, 세그먼트 선택(선형 아이콘), 입력창·시트를 공용 컴포넌트로 정리해 모든 화면에 적용한다.
- 알림 화면은 라이트 모드에서도 항상 다크로 둔다(밤·대중교통에서 눈부심 방지).
- README 와 디자인 문서를 함께 고친다.
