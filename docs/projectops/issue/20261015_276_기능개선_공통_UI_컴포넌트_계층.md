### 📝 현재 문제점

- #272 로 색·글자 체계는 공통화됐지만, 바텀시트 9개가 머리(아이콘·제목·설명)·여백·스크롤·안전 영역을 각자 손으로 짜고 있다. 여백 값도 시트마다 다르고, 글자를 키우면 넘치는 문제를 시트마다 따로 막아야 한다.
- 목록 한 줄(아이콘·제목·부제·오른쪽 화살표/스위치/값)을 설정·장소 폼·알림음 선택이 각자 만든다.
- 칸 제목(`PlaceSectionLabel`)이 places 안에만 있어 다른 화면이 쓸 수 없다.
- 이름이 역할을 드러내지 않는 것이 있다(`context.typo`, `context.palette` 등).

### 🛠️ 해결 방안

- `lib/core/ui/` 디자인 시스템 계층(foundation · components · feedback)을 두고 화면은 이 계층만 조립한다.
- 공통 컴포넌트: `showAppBottomSheet` + `BottomSheetWithHeaderLayout`, `GroupedListRow`(navigation · toggle · value · selectable), `GroupedListSection`, `SectionTitleWithTrailingValue`, `IconLabelSegmentedControl`, `StatusBarIconsFollowingTheme`.
- 이름을 직관적으로 바꾼다: `context.appColors`, `context.appTextStyles`, `AppColorPalette`, `wrapWithAlwaysDarkAlertTheme` 등.
- 화면에서 `showModalBottomSheet`·`ListTile` 직접 사용을 규칙 테스트로 막는다.
- 전체 아키텍처 검수 결과 중 함께 고칠 것을 반영한다.
- 문서: `docs/02-ARCHITECTURE.md` 디자인 시스템 계층, `docs/06-UX.md` 컴포넌트 목록, 결정 기록.
