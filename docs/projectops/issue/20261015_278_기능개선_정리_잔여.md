### 📝 현재 문제점

#276 아키텍처 검수에서 미뤄 둔 것과 작업 중 드러난 것이다.

- `current_location_failure_test` 의 "내 위치 측정이 늦으면 다시 눌러달라고 안내한다" 가 전체 테스트를 돌릴 때만 간헐적으로 실패한다(단독 실행은 통과).
- 알림음 선택 시트가 저장소 목록과 이어폰 연결 상태를 `setState` 로 들고 있다(docs/04-CONVENTIONS — 화면 데이터는 Riverpod).
- "내 위치로 이동"(실패 안내 + 카메라 이동) 흐름이 지도 홈과 위치 선택 화면에 거의 같게 두 벌 있고, 홈 쪽은 성공 로그가 없다.
- 광고 단위 ID(`features/ads/domain/ad_unit_ids.dart`)가 domain 인데 `package:flutter/foundation` 을 import 한다.

### 🛠️ 해결 방안

- 흔들리는 테스트의 원인(실시간 타이머·시간 초과)을 찾아 결정적으로 만든다.
- 알림음 시트의 목록·이어폰 상태를 `@riverpod` provider 로 옮긴다.
- "내 위치로 이동"을 공용 함수 하나로 모으고 성공·실패 로그를 남긴다.
- 빌드 모드 판정을 data 쪽으로 옮겨 domain 을 순수 Dart 로 만든다. 경계 테스트에 foundation 금지를 더한다.
