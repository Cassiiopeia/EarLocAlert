### 🗒️ 설명

홈의 장소 목록 시트를 끝까지 올리면 지도 위 버튼(장소 추가 `+`, 내 위치)이 시트를 따라 올라가 상단의 설정 버튼과 상태바를 덮는다. 그 상태에서 설정 버튼 자리를 누르면 설정이 아니라 장소 등록이 열린다.

### 🔄 재현 방법

1. 장소를 여러 개 등록한다.
2. 홈의 목록 시트를 끝까지 끌어올린다.
3. 오른쪽 위에서 `+`·내 위치 버튼이 설정 버튼 위에 겹친다. 설정 버튼을 누르면 장소 등록 화면이 열린다.

### ✅ 예상 동작

시트가 상단 막대 근처까지 올라오면 지도 버튼은 숨고 눌리지 않는다. 시트를 내리면 다시 보인다.
