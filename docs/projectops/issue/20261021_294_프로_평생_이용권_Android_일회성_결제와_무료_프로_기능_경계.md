📝 현재 문제점
---

- 수익원이 광고뿐이다. 알림 해제 후 전면광고와 하단 띠가 지면의 전부라 구조적으로 수익이 작다 (`docs/07-MONETIZATION.md` 기대치).
- 앱에 돈을 낼 이유가 없다. 모든 기능이 무료로 열려 있다.
- 광고 제거 인앱결제(#257)는 iOS 유료 앱 계약 미서명으로 보류돼 있다. Android 는 막힌 것이 없다.

🛠️ 해결 방안 / 제안 기능
---

**구독이 아닌 한 번 결제 "평생 이용권"(₩6,500)으로 프로를 판다. 이번에는 Android 만.**

- 목표: 판매 1건당 수수료·부가세 제외 약 5,000원 (₩6,500 ÷ 1.1 × 0.85 ≈ 5,020원, Play 15% 구간 기준).
- iOS 는 이번에 바꾸지 않는다. 지금처럼 전 기능 무료 + 광고. iOS 실기기 기능 검증이 덜 되어 있어서다.
- 로그인·서버 없음. 구매는 Play 가 기기의 구글 계정에 묶어 기억하고, 재설치·기기 변경 시 "복원하기"로 되찾는다.

**무료 / 프로 경계**

| 기능 | 무료 | 프로 |
|---|---|---|
| 장소 | 1개 | 제한 없음 (실제 상한 30, 닿으면 "기기 한도에 도달했어요") |
| 도착·출발 알림 | ✓ | ✓ |
| 알림 시간대 | ✓ | ✓ |
| 진동 세기 조절 | ✓ | ✓ |
| 이어폰 알림음 | 기본 1개 고정 | 프리셋 전체 + 장소별 지정 + 내 음원 등록 |
| 장소 백업·가져오기 | 불가 | ✓ |
| 광고 (전면 + 하단 띠) | 있음 | 없음 |
| 알림 발화·해제, 이어폰 판정, 권한, 진단 기록 | 동일 | 동일 |

알림이 울리고 꺼지는 경로와 알림 신뢰성에 필요한 권한은 절대 막지 않는다.

**프로 안내 시트 (비교표형, 모든 진입점 공통)**

제목 "평생 이용권", 부제 "구독 아님 · 기기 바꿔도 같은 계정이면 유지", 구매 버튼 "평생 이용권 {Play 현지화 가격}", 맨 아래 "이미 구매했나요? 복원하기".

![i1-sheet](https://github.com/Cassiiopeia/EarLocAlert/releases/download/qa-evidence/pro-lifetime_20261021-235812_i1-sheet.png)

**무료/프로 상태 표시**

- 홈 상단 칩: 무료는 회색 `FREE`(누르면 프로 시트), 프로는 민트 `PRO`.
- 설정 맨 위: 무료는 큰 유도 카드("장소 1/1 사용 중", "장소를 제한 없이 등록하세요", 구매 버튼), 프로는 한 줄 `PRO 평생 이용권`, 기존 사용자는 옆에 "기존 사용자 혜택".

![i2-status](https://github.com/Cassiiopeia/EarLocAlert/releases/download/qa-evidence/pro-lifetime_20261021-235814_i2-status.png)

**잠긴 기능 표시: 블러 + 가운데 버튼 (자물쇠 없음)**

- 알림음 선택: 기본음만 선택 가능, 나머지 프리셋과 내 음원 섹션을 흐리게, 가운데 "평생 이용권으로 열기".
- 홈 장소 목록(무료 + 장소 1개): "장소 추가" 자리에 흐린 예시 장소 2개 + 버튼.
- 백업·가져오기 메뉴도 같은 방식.

![i3-blur](https://github.com/Cassiiopeia/EarLocAlert/releases/download/qa-evidence/pro-lifetime_20261021-235815_i3-blur.png)

**동작 규칙**

- 구매 즉시 광고 중단·제한 해제, 구매 확인(acknowledge) 필수.
- 오프라인이면 마지막 확인 상태 유지. 오프라인을 이유로 프로를 빼앗지 않는다.
- 환불되면 무료로 전환하되 이미 등록된 장소·알림음은 계속 동작. 추가와 다른 음으로 바꾸기만 막는다.
- 결제 대기(pending)는 프로로 열지 않는다.
- 알림 화면, 해제 직후, 온보딩 중에는 결제 화면을 띄우지 않는다.

**기존 사용자 혜택**

- 업데이트 후 첫 실행에 한 번 판정해서 기기에 장소가 있으면 프로를 무료로 준다.
- 재설치로 혜택을 잃은 사람은 Play Console 프로모션 코드로 대응한다.

⚙️ 작업 내용
---

- 결제 연동 (Play 일회성 상품 `pro_unlock`, 복원, 환불·대기 처리)
- 등급별 장소 상한 단일화 (무료 1 / Android 프로 30 / iOS 20), 감시 동기화 상한 맞춤
- 프로 안내 시트, 홈 칩, 설정 카드, 블러 잠금 공통 컴포넌트
- 진입점 연결: 장소 추가, 알림음 선택, 백업·가져오기
- 프로일 때 광고 요청 중단 (알림 해제는 광고·결제와 무관하게 즉시 완료 유지)
- 기존 사용자 판정 (Android, iOS 는 기록만)
- 네 언어 문구, `[pro]` 진단 로그, 테스트
- 문서: `docs/10-DECISIONS.md`, `docs/07-MONETIZATION.md`, `docs/11-ROADMAP.md`
- 설계 원문: `docs/superpowers/specs/2026-10-21-pro-lifetime-purchase-design.md`

**사용자 작업 (선행)**

- Play Console 판매자 결제 프로필 완료
- 일회성 상품 `pro_unlock` 생성, 가격 ₩6,500
- 라이선스 테스터 등록
