# 알림, 앱 이름, 권한 문구를 기기 언어로 보인다

## 개요

알림은 앱이 죽어 있어도 Kotlin 이 만들기 때문에 Flutter 의 번역을 쓸 수 없다. 상태바 알림, 알림 채널 이름, 앱 표시 이름, iOS 권한 안내를 네 언어 리소스로 옮기고, **앱에서 고른 언어를 네이티브가 알게** 했다.

## 변경 사항

### Android
- `res/values{,-ko,-ja,-zh-rCN}/strings.xml`(신규): 감시 알림 제목과 내용, 알림 채널 이름과 설명, 도착/출발 문구, 끄기 버튼, 앱 이름. 기본(`values`)은 영어라 지원하지 않는 기기 언어는 영어다. 중국어는 간체(`zh-rCN`)만 있어 번체 기기는 영어다.
- `AppLocale.kt`(신규): 앱에서 고른 언어를 적용한 컨텍스트. `flutter.app_language` 를 읽는다(**Dart 의 `AppLanguageStore.key` 와의 계약**).
- `AlertWatchService.kt`: 문구를 리소스에서 읽는다. **채널이 이미 있어도 다시 만든다** — OS 는 채널 이름과 설명을 만든 시점의 언어로 굳히지만 같은 아이디로 다시 만들면 이름과 설명만 갱신되고 진동과 소리 설정은 그대로 남는다.
- `AndroidManifest.xml`: 앱 이름을 `@string/app_name` 으로.

### iOS
- `{en,ko,ja,zh-Hans}.lproj/InfoPlist.strings`(신규): 위치 권한 3건, 광고 추적 안내, 앱 표시 이름. `Info.plist` 기본값은 영어, `CFBundleLocalizations` 추가, Xcode 프로젝트에 변형 그룹 등록.

### Dart
- `GeofenceRegistrationSync.refresh()` 와 설정의 언어 변경: 언어를 바꾸면 감시 등록을 다시 밀어 넣어 서비스가 새 언어로 알림을 다시 만든다.

## 주요 구현 내용

**검증 (에뮬레이터 API 36, 언어를 바꿔 가며 상태바 알림과 채널 이름 확인)**

| 앱 언어 | 알림 제목 | 채널 이름 |
|---|---|---|
| 기기(영어) | Watching your locations | Location watching |
| ko | 위치를 지켜보고 있습니다 | 위치 감시 |
| ja | 位置を見守っています | 位置の見守り |
| zh | 正在监测您的位置 | 位置监测 |
| en | Watching your locations | Location watching |

**언어를 바꿀 때마다 채널 이름이 새 언어로 갱신되는 것**까지 확인했다. iOS 시뮬레이터 빌드로 네 언어 폴더와 권한 키 3건이 번들에 들어가고 `CFBundleLocalizations` 가 네 언어인 것을 확인했다.

## 주의사항

- **iOS 권한 안내는 OS 가 기기 언어로 고른다.** 앱 안에서 고른 언어와 어긋날 수 있다.
- 도착 알림(`arrival_*` 문구)은 리소스로 옮기고 컴파일을 확인했지만 **에뮬레이터에서 실제로 발화시켜 보지는 못했다**(백그라운드에서 이 에뮬레이터가 주입한 위치를 전달하지 않는다). 실기기 확인이 필요하다.
- 앱 표시 이름은 한국어만 현지 이름이고 나머지는 `EarLocAlert` 다(스토어 제목은 Console 에서 정한다, #166).
- 울리고 있는 알림 세션은 언어 변경의 영향을 받지 않는다. 다음 알림부터 새 언어다.
