# 진단 로그를 영어로 통일한다

## 개요

앱을 해외에서 쓰면(#163) 내보낸 로그를 읽는 쪽도 여러 언어를 마주한다. 로그는 사용자 화면이 아니라 개발자와 지원이 읽는 기록이라 번역 대상이 아니다. Dart `Diagnostics.log` 와 Kotlin `DiagnosticLog.write` 의 메시지를 영어 고정 토큰으로 바꿨다. 앱 언어와 무관하게 항상 영어다.

## 변경 사항
- Dart 호출 69곳, Kotlin 38곳의 메시지를 영어로. 형식은 `[tag] event key=value`, 사유는 고정 토큰(`reason=location_jump`)이다. 태그와 `key=value` 는 그대로다.
- 사유 라벨(`AlertSuppression.label`), 시작 사유(`boot`, `package_replaced`, `watchdog`, `system_restart`), 종료 사유(`ExitReasonLogger`), 경과 표기(`3h12m ago`, `never`)를 토큰으로.
- 테스트의 로그 문구 기대값을 새 표기로.
- `docs/04-CONVENTIONS.md` 에 **옛 표기 → 새 표기 대응표**, `CLAUDE.md` 규칙 7, 결정 040.

## 주요 구현 내용

- **번역표를 코드로 적용한 뒤 기계적으로 검사했다.** `Diagnostics.log(` 와 `DiagnosticLog.write(` 호출을 괄호 짝으로 추출해 한글이 남은 호출이 0건임을 확인했다. 이 검사가 처음 목록에서 빠진 두 곳(홈 상태 로그, 예외 메시지)을 잡았다.
- 이후 `test/core/l10n/no_hardcoded_korean_test.dart`(#163)가 `lib/` 전체의 한글 리터럴을 막는다 — 로그도 예외가 아니다.
- 화살표는 ASCII(`->`)다. 옛 표기의 `→` 를 기대하던 테스트를 함께 고쳤다.

## 주의사항

- **옛 로그는 한국어다.** 이미 내보낸 로그와 이전 보고서(#93~#159)는 옛 표기다. 대응표(`docs/04-CONVENTIONS.md`)로 읽는다.
- 로그 테스트의 한국어 문구는 로그 파일을 읽고 쓰는 입출력 검증의 **픽스처**였다. 실제 메시지와 무관해서 영어 픽스처로 바꿨다.
- 새 로그도 영어로 쓴다. 한글 문장을 넣으면 테스트가 실패한다.
