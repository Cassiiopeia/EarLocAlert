# 해외 사용을 막는 한국 전제를 점검한다

## 개요

번역만으로는 해외에서 쓸 수 없다. 코드와 문서에 남은 "사용자는 한국에 있다"는 전제를 찾아 걷었다. 이번에 코드로 처리한 것: 지도 시작 화면, 광고 동의, 릴리스 노트 네 언어. 콘솔 작업이 필요한 것은 분리해 남겼다.

## 변경 사항

- `lib/core/map/default_map_view.dart`(신규): 기기 지역(국가)으로 시작 화면을 고른다(KR 서울, JP 도쿄, CN 베이징, TW 타이베이, HK 홍콩, US 뉴욕, GB 런던, 그 밖은 세계 지도). 홈과 지도 선택 화면의 서울시청 고정을 없앴다. 지도 선택 화면은 세계 지도일 때 반경에 맞춘 확대를 하지 않는다.
- `features/ads/domain/ad_consent.dart`, `data/google_ad_consent.dart`(신규): UMP 광고 동의. `GoogleInterstitialAdService.preload` 가 광고를 요청하기 전에 `canRequestAds()` 를 확인한다(**모르면 요청하지 않는다**). 앱 시작 때 동의 정보를 갱신하고 필요하면 동의 화면을 띄운다. **알림이 울리는 중이면 띄우지 않는다.**
- `release-notes/{en-US,ja-JP,zh-CN}/1.19.0.txt`, `.github/scripts/prepare_play_changelogs.sh`(#167): Play 릴리스 노트 네 언어.
- 결정 042, `docs/07-MONETIZATION.md`.

## 주요 구현 내용

- **광고 동의는 문서에만 있었다.** `07-MONETIZATION`(F8.5)에 적혀 있었지만 코드에는 동의 수집이 없었고 `MobileAds` 초기화도 없이 광고를 바로 요청했다. 유럽 경제 지역과 영국 사용자에게 동의 없이 광고를 요청하면 계정이 위험해진다. 규칙 3(알림 화면에 광고를 겹치지 않는다)과 같은 이유로 알림이 울리는 중에는 동의 화면도 띄우지 않는다.
- 위치를 얻으면 곧바로 거기로 옮겨지므로 시작 화면은 잠깐만 보인다. 그래도 서울을 모두에게 보이지 않는다.
- 테스트: 시작 화면 규칙 4건, 동의 게이트 2건. 전체 583건 통과.

## 주의사항

- **AdMob 콘솔에서 유럽 규정 메시지를 만들어야 동의 화면이 뜬다**(사용자 작업). 없으면 코드는 화면 없이 지나간다.
- **Play Console 확인은 아직 못 했다.** 스토어 등록정보 네 언어, 앱 제목, 심사 상태는 콘솔 로그인이 필요하다.
- 미결: 주소 검색 제공자(카카오는 일본, 중국에서 안 된다), 중국 본토에서 구글 지도 동작 여부, 지도 라벨 언어. 결정 042 참조.
- 알림 미리보기의 예시 좌표(서울시청)는 미리보기 전용이라 그대로 뒀다.
