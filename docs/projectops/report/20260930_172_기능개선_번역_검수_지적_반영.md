# 번역 검수 지적을 반영해 용어를 통일한다 — 상세 기록

## 개요
영어·일본어·중국어 번역을 **언어별로 독립된 검수자**(번역한 맥락 없이 원문과 대조)가 검수했다. 의미 누락·플레이스홀더 훼손은 없었고, 지적은 **용어 혼용**, **안드로이드 실제 설정 표기와의 불일치**, **직역투**, **오역**이었다. 확실한 것만 반영했고 1.20.1(빌드 111)로 배포했다. 일본어 권한 설명 4건은 실기기 캡처를 보다가 추가로 고쳤다(다음 배포에 포함).

## 확인된 것과 아닌 것
- 확인: 분석 오류 0건, 테스트 통과, 에뮬레이터에서 4개 언어 설정·홈 화면 렌더링
- 확인 못 함: 일본어·중국어 장소 등록 화면 캡처(자동화가 설정 화면 뒤에서 멈춤), 알림이 실제로 울릴 때의 네이티브 문구, iOS 권한 문구
- 스토어 본문의 용어 통일은 구글 검토가 끝난 뒤 콘솔에 반영한다
- 번역은 LLM 번역을 독립 검수한 것이며 원어민 검수는 남아 있다
