# 번역 검수 지적을 반영해 용어를 통일한다

## 개요
영어·일본어·중국어 번역을 언어별 독립 검수자로 검수해, 의미가 확실한 지적만 반영했다. 1.20.1(빌드 111)로 배포됐다.

## 변경 사항
- 영어: 권한 이름을 안드로이드 설정 표기로(Unrestricted battery use, Full-screen notifications, Allow all the time), watching→monitoring, alert hours→time range, headphones→earphones(한국어 원문 "이어폰"과 일치), 알림 "You've arrived/left"
- 일본어: "バイブ" 약어 제거, 見守り→監視, "解除" 단독 버튼→"アラートを止める", 업데이트 안내 "ダウンロードしました", USB-C 이어폰 명시
- 중국어: 解除→关闭, 알림음 오역 정정(和弦音→风铃声, 警笛→警报声, 钟声→铃声), 忽略电池优化·显示在其他应用的上层 표기 통일
- 안드로이드 네이티브 알림 문구와 스토어 본문 초안(`docs/store/descriptions/`)도 같은 기준

## 주의사항
- 스토어 본문의 용어 통일은 콘솔에 아직 반영하지 않았다(구글 검토 진행 중이라 검토가 끝난 뒤 반영).
- 영어 진단 화면 건수의 복수형은 반영하지 않았다.
- 번역은 LLM 번역을 독립 검수한 것이며 원어민 검수는 남아 있다.
