# AdMob 계정 승인과 유럽 규정 동의 메시지 게시 (2026-10-01)

## 개요
6개월 광고 미게재로 비활성화됐던 AdMob 계정(게시자 `pub-2025665624324395`)이 재활성화 승인을 받았다. 승인 메일 수신 후 콘솔에서 상태를 직접 확인했고, 계정 승인 대기 때문에 막힌 줄 알았던 유럽 규정(UMP) 동의 메시지를 게시했다.

## 확인한 상태

| 항목 | 상태 |
|---|---|
| 계정 | 승인됨 (홈에서 "축하드립니다, 이제 계정을 사용하실 수 있습니다" 메일 수신) |
| 지급 프로필 | 완료 (기존 기본 프로필 자동 연결) |
| 앱 `이어폰 위치 알림` | 아직 "검토 필요", 수익 US$0.00 |
| 유럽 규정 메시지 | **게시됨** |

## 유럽 규정(UMP) 메시지 게시
- 이름 `EarLocAlert EEA UK consent`, 앱 `이어폰 위치 알림` 1개만 선택 (ELUM 앱은 건드리지 않음)
- 기본 언어 영어(en), 추가 언어 일본어(ja)·중국어(zh-CN)
- 사용자 선택사항: 동의 사용, 옵션 관리 사용, 동의하지 않음 사용 안함, 닫기 사용 안함
- 목록에서 상태 "게시됨" · 게시 스위치 켜짐 확인. 앱에 반영되기까지 최대 1시간
- 개인정보처리방침 URL: `https://cassiiopeia.github.io/EarLocAlert/privacy.html` (앱에 저장돼 있던 값)

## 게시가 막혔던 진짜 원인
어제까지 "게시" 버튼이 비활성이라 계정 재활성화 검토 때문이라고 추정했으나 **틀렸다.** 편집기의 "사용자 선택사항 → 동의하지 않음"이 미선택(placeholder "선택") 상태였고, "사용 안함"으로 정하자 버튼이 활성화됐다. 이 항목이 비면 화면에 이유가 나오지 않는다.

## 주의사항
- 앱 선택 창에서 행의 첫 번째 `input[type=checkbox]` 는 앱 체크박스가 아니라 **"대체 동의 수집" 토글**이다. 자동 조작 중 토글이 한 번 켜졌고 즉시 꺼서 원복했다. 게시본은 토글 꺼짐 상태다
- 앱 상태 "검토 필요"는 Play 공개 게시 뒤 AdMob 앱 설정에서 스토어 연결(앱 인증)을 해야 풀린다. 현재 비공개 테스트 단계라 패키지 검색에 나오지 않는다
- 브라우저 조작 함정: pro-launch `web click` 은 iframe 안(메시지 편집기 `display-ads-user-messaging-embed`)에 못 들어간다. CDP 로 붙어 프레임을 직접 다뤄야 한다. 이전에 띄운 Chrome 이 프로필을 잡고 있으면 `browser_start_failed` 가 나므로 `browser.json` 의 CDP 포트로 붙는다
