# 스토어 홍보 이미지와 소개 페이지 검색 노출 개선 — 구현 보고서

## 개요

스토어 스크린샷이 화면 캡처 그대로라 무엇을 하는 앱인지 한눈에 안 들어왔고, 소개 페이지(github.io)에는 스토어 다운로드 버튼과 검색엔진용 정보, 영어 외 언어 페이지가 없었다.

- 설계: `docs/superpowers/specs/2026-10-15-store-marketing-and-landing-design.md`
- 스토어: App Store 1.36.0 심사 제출, Google Play 등록정보 4개 언어 갱신

## 변경 사항

### 홍보 이미지 생성기 (`tool/store_art/`)
- `render.py` + `scenes.json` + HTML 틀: 홍보 문구와 일반 휴대폰 모양 테두리로 합성한다(애플·구글 기기 이미지와 상표는 쓰지 않는다). 글꼴은 레포의 Pretendard.
- 문구는 한국어·영어·일본어·중국어 4개 언어 사전이고, iOS 1번 이미지는 알림 방식이 달라 문구를 따로 둔다(`sub_ios`).
- 결과(`docs/store/promo/<언어>/`): iOS 1206×2622 6장, Android 1080×1920 6장, Play 그래픽 이미지 1024×500, 공유 이미지 1200×630. 캡처 원본은 `docs/store/promo/source/`.
- App Store 의 "Dynamic Island 지원 iPhone(중형 디스플레이)" 칸은 1179×2556·1206×2622 만 받는다. 처음 만든 1320×2868 은 "파일 크기가 유효하지 않습니다"로 거절돼 1206×2622 로 다시 뽑았다.

### 소개 페이지 (gh-pages)
- App Store·Google Play 공식 배지, 자주 묻는 질문 6개, 앱 정보·FAQ 구조화 데이터, 검색어 중심 제목·설명, canonical·hreflang, `sitemap.xml`, `robots.txt`.
- 영어·일본어·중국어 페이지를 한국어 페이지에서 `tool/store_art/landing/make_lang_pages.py` 로 생성한다(본문에 한국어가 남으면 실패). 한국어 첫 화면에는 홍보 영상을 소리 없이 자동 반복한다.
- 언어별 홍보 이미지 6장과 언어별 공유 이미지.

### 스토어 업로드 (브라우저 자동화, `tool/store_art/upload/`)
- App Store Connect: 새 버전을 만들고 4개 언어 스크린샷·프로모션 문구·새 기능 문구를 채워 **1.36.0(빌드 88036239)을 심사 제출**했다. 스토어 버전 번호는 빌드의 버전과 같아야 해서 1.35.2 로 만들었던 것을 1.36.0 으로 고쳤다.
- Google Play: 4개 언어의 그래픽 이미지와 휴대전화 스크린샷 6장을 교체했다(제출 56 — 변경사항 8개, "출시됨"). 이후 스크린샷 순서(한국어에서 04 가 맨 뒤로 가던 문제)와 중복(12/8, 2/1)을 바로잡아 다시 저장했다.
- 옛 그래픽 이미지는 "Get it on Google Play" 배지와 AirPods 이미지가 들어 있어 Play 메타데이터 정책에 걸릴 소지가 있었는데, 새 이미지로 대체됐다.

## 검증

- 생성한 이미지는 직접 열어 확인했다(문구 잘림, 휴대폰 전체 노출, 4개 언어 글자).
- 소개 페이지는 4개 언어 모두 참조 파일 누락 0건, 구조화 데이터 구문 검사 통과, 본문에 번역 안 된 한국어 0건.
- App Store: "1.36.0 심사 대기 중". Play: 편집기에서 4개 언어 모두 그래픽 1/1, 스크린샷 6/8, 순서 01→06 확인, 대시보드 "게시되지 않은 변경사항이 없습니다".

## 주의사항

- **Play 순서·중복 수정본은 새 제출 기록이 따로 보이지 않는다.** 등록정보 화면에는 "변경사항을 전송하여 검토받을 수 있음" 표시가 남아 있고 게시 개요에는 전송 버튼이 보이지 않는다. 관리형 게시가 꺼져 있어(승인 후 자동 게시) 다음 심사 결과에서 반영 여부를 다시 확인한다.
- Android 일본어 스크린샷은 장소 이름이 "板橋駅"(일본에서는 도쿄 이타바시역으로 읽힘)인 판이다. iOS 일본어는 "パンギョ駅" 이다. 맥 메모리가 부족해 다시 찍지 못했고, 다시 찍으면 같은 생성기로 바꿔 올리면 된다.
- 공유 브라우저(pro-launch)를 다른 세션이 이동시키면 저장 전 편집이 사라진다. Play 편집은 언어마다 "임시보관함에 저장"을 누르며 진행한다.
- Search Console·네이버 서치어드바이저 등록은 사용자 작업이다.
