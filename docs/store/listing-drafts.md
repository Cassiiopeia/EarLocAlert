## 콘솔에서 해야 할 일 (사용자 작업, 읽기만 확인했다)

1. **사용자 늘리기 → 앱 정보 → 스토어 등록정보 → 번역 관리 → 언어 선택**에서 영어(en-US), 일본어(ja-JP), 중국어 간체(zh-CN)를 추가한다.
2. 각 언어에 위 제목과 설명을 붙여 넣고 **그래픽(그래픽 이미지, 스크린샷)** 을 언어별로 올린다. **지금 그래픽 이미지에 한국어 문구가 있다**("가야 할 곳 지나치지 않도록"). 언어를 추가하면 현지화된 그래픽이 없을 때 기본 언어 그래픽이 쓰인다.
3. **비공개 테스트의 국가/지역**은 지금 **대한민국 1개국**이다. 해외에서 쓰게 하려면 국가를 추가한다.
4. **AdMob 콘솔**에서 유럽 규정 메시지를 만든다(광고 동의 화면이 뜨려면 필요, #166).

## 2026-09-30 콘솔 반영 결과

- 스토어 등록정보에 **en-US · ja-JP · zh-CN 을 추가하고 위 제목·간단한 설명·자세한 설명 전문을 넣어 저장했다.** 전문은 `docs/store/descriptions/` 에 있다(ko-KR 은 콘솔 원문).
- **2026-09-30 사용자 승인으로 구글 검토에 전송했다.** 게시 개요에 "검토 중인 변경사항" 3건이 올라가 있다(일반적으로 7일 이내). 번역은 기계 번역이므로 원어민 검수는 남아 있다.
- 아이콘·그래픽 이미지·스크린샷은 한국어 기본 자료가 그대로 쓰인다(현지화 미완).
- **비공개 테스트 국가 확대는 하지 않았다.** 편집 화면이 자동 조작에 맞지 않아 잘못 눌릴 위험이 있었다. 콘솔에서 직접 추가한다. **유럽 경제 지역·영국은 AdMob 동의 메시지를 만든 뒤에 넣는다**(#166).
