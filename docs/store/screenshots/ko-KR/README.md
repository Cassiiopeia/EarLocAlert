# Google Play 휴대전화 스크린샷 (ko-KR)

2026-10-10 에 현재 빌드(v1.27.2, 디버그)로 다시 찍었다 (이슈 #244). 순서가 곧 스토어 노출 순서다.

| 순서 | 파일 | 보여주는 것 |
|---|---|---|
| 1 | `01_alert.png` | 도착 알림 화면 — 장소 이름, 반경 원이 그려진 지도 카드, 큰 "알림 끄기" 버튼 |
| 2 | `02_home.png` | 홈 지도 — 감시 중, 등록한 장소의 반경 원과 목록(요일·시간대 포함) |
| 3 | `03_form.png` | 장소 편집 — 반경, 도착/출발/둘 다, 알림 시간대, 이어폰 전용 소리 |
| 4 | `04_sound.png` | 장소별 알림음 — 기본 5종과 내 음원 등록 |
| 5 | `05_picker.png` | 지도에서 위치를 고르고 반경을 정하는 화면 |
| 6 | `06_settings.png` | 설정 — 진동 세기, 알림음 크기, 알림 도달 권한 |

- 규격: 1080 x 2160 PNG (Play 는 긴 변이 짧은 변의 2배 이하여야 한다. 1080 x 2400 은 올라가지 않는다)
- 기기: Android 에뮬레이터 `Medium_Phone_API_36.1` (`wm size 1080x2160`), 한국어, 상태 막대는 demo mode
- 샘플 장소: 판교역 `회사 출근`(반경 500m), 서현역 `퇴근 집 도착`(반경 650m) — 공개된 지역 좌표다
- 알림 화면(1번)은 에뮬레이터 위치를 반경 밖에서 안으로 옮겨 **실제 지오펜스 진입**으로 띄웠다. 이어폰이 없는 상태라 "진동으로만 알림 중"이 보인다
- 테스트 광고 띠가 보이지 않는 화면만 골랐다. 광고가 있는 상태에서 찍은 것은 쓰지 않았다
- 이 이미지에는 iOS 화면이 들어 있지 않다. iOS 는 알림 동작이 달라 따로 찍는다 (이슈 #245)
