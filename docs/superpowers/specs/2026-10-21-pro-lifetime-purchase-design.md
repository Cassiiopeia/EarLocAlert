# 프로 평생 이용권 (Android 일회성 결제) 설계

작성일: 2026-10-21 · 관련: #257(광고 제거 인앱결제, 보류) 흡수

## 1. 의도

광고만으로는 수익이 구조적으로 작다([07-MONETIZATION](../../07-MONETIZATION.md) "기대치"). 이 앱에 돈을 낼 만한 이유를 하나 만든다.

- **구독이 아니라 한 번 결제(평생 이용권)** 다. 이 앱의 기능량으로 구독은 정당화가 어렵다(07 문서의 기존 판단과 같다).
- 목표 수익: 판매 1건당 **수수료·부가세 제외 약 5,000원**.
  - 판매가 **₩6,500** → ÷1.1(부가세) × 0.85(Play 15% 수수료 구간) ≈ 5,020원.
  - Play 는 연 100만 달러까지 15% 다. 종합소득세는 이 계산 밖이다.
- 무료는 "핵심을 확실히 경험하지만 두 번째 장소에서 막히는" 최소안이다.

## 2. 범위

- **Android 만.** iOS 는 실기기 기능 검증이 덜 되어 이번에 손대지 않는다.
- iOS 는 **현재 그대로**: 전 기능 무료 + 광고. 프로 시트·설정 프로 항목도 보이지 않는다.

## 3. 무료 / 프로 경계 (확정)

| 기능 | 무료 | 프로 |
|---|---|---|
| 장소 | **1개** | **제한 없음** (화면 표기) |
| 도착·출발 알림 | ✓ | ✓ |
| 알림 시간대 | ✓ | ✓ |
| 진동 세기 조절 | ✓ | ✓ |
| 이어폰 알림음 | **기본 1개 고정** (`SoundPreset.defaultTone`) | 프리셋 전체 + 장소별 지정 + 내 음원 등록 |
| 장소 백업·가져오기 | **불가** | ✓ |
| 광고 (전면 + 하단 네이티브 띠) | 있음 | **없음** |
| 알림 발화·해제, 이어폰 판정, 권한, 진단 기록 | 동일 | 동일 |

**절대 막지 않는 것**: 알림이 울리고 꺼지는 경로, 알림 신뢰성에 필요한 권한. 이것을 막으면 무료 사용자에게 앱이 고장 난 것으로 보인다.

### 장소 "제한 없음"의 실제 상한 (확정)

- 현재 `PlaceValidator.maxPlaces = 20` 은 iOS OS 제한 기준으로 두 플랫폼 공용이다. 감시 동기화(`lib/app/geofence_registration_sync.dart` `maxTargets = 20`)에도 20 이 따로 걸려 있다.
- Android OS 는 앱당 지오펜스 **100개** 가 상한인데, 장소 1개가 원 3개(본 원·근접 원·바깥 원 — `GeofenceRegistrar.kt` `sync()`)를 쓴다 → 실질 약 33개. 넘기면 등록 요청 전체가 실패해 **모든 알림이 꺼질 수 있다.**
- **Android 프로 실제 상한 = 30.** 화면 표기는 "제한 없음". 30 에 닿으면 "기기 한도에 도달했어요" 안내(프로 시트가 아니라 안내 — 이미 프로다).
- 감시 동기화 상한도 같은 값으로 맞춘다(Android 30 / iOS 20). 장소 등록 상한과 감시 상한이 어긋나면 등록됐는데 안 울리는 장소가 생긴다.
- 상한은 플랫폼·등급별로 **한 곳에서** 계산한다(무료 1 / Android 프로 30 / iOS 20). 등록 검증·감시 동기화·백업 가져오기·화면 표기가 모두 그 값을 읽는다.
- 장소당 원 개수를 줄이는 구조 변경은 하지 않는다(실기기 검증 없이 백그라운드 감시를 건드리지 않는다).

## 4. 결제 화면 — 프로 안내 시트 (확정)

비교표형(B안) 바텀시트 **하나**를 모든 진입점이 공유한다.

```
[PRO 배지]
평생 이용권                                   ← 제목
구독 아님 · 기기 바꿔도 같은 계정이면 유지     ← 부제

            무료        프로
장소         1개         제한 없음
도착·출발 알림 ✓          ✓
알림 시간대   ✓          ✓
진동 세기    ✓          ✓
이어폰 알림음 기본 1개    전체 + 내 음원
장소 백업    —          ✓
광고        있음        없음

[ 평생 이용권 ₩6,500 ]                       ← 구매 버튼 (민트 accent)
이미 구매했나요? 복원하기                     ← 맨 아래 텍스트 버튼
```

- 시안 원본: `.superpowers/brainstorm/75571-1792593498/content/pro-sheet-final.html`
- **가격은 Play 가 주는 현지화 가격 문자열을 쓴다**(`ProductDetails.price`). ₩6,500 을 코드에 박지 않는다. 상품 정보를 못 읽으면 구매 버튼을 비활성 + 사유 문구.
- 문구는 네 언어(ko·en·ja·zh) arb 에 넣는다. ko 는 위 확정 문구, 나머지는 **(설계자 판단)** 같은 뜻으로 번역.
- 디자인 시스템(`lib/core/ui/`)의 시트·색 토큰만 쓴다. 다크/라이트 두 벌.

### 시트가 뜨는 곳

1. 무료 + 장소 1개 보유 상태에서 **장소 추가**
2. 알림음 선택에서 **기본음 외 프리셋 또는 내 음원** 선택·등록
3. **백업·가져오기** 메뉴
4. **설정 맨 위 카드**의 구매 버튼
5. **홈 상단 FREE 칩**

## 4-1. 무료/프로 상태 표시 (확정)

두 곳에 보인다 — 홈은 짧게, 설정은 자세히.

**홈 상단 칩** — 기존 상단 상태 표시 줄 오른쪽(설정 버튼 옆).
- 무료: 회색 `FREE` 칩. 누르면 프로 시트.
- 프로: 민트 `PRO` 칩. **(설계자 판단)** 누르면 아무것도 하지 않는다.

**설정 맨 위** — 시안 원본: `.superpowers/brainstorm/75571-1792593498/content/settings-card-v2.html`
- 무료 → **큰 유도 카드** (무료 B안):
  ```
  [FREE]                         장소 1/1 사용 중
  장소를 제한 없이 등록하세요
  알림음 전체 · 장소 백업 · 광고 없음
  [ 평생 이용권 ₩6,500 ]          ← Play 현지화 가격
  ```
  "장소 n/1 사용 중"은 실제 등록 수.
- 프로 → **한 줄 행**만: `[PRO] 평생 이용권 ›`. 누르면 구매 상태·복원 정도만 보이는 작은 화면/시트(빌더 재량).
- 기존 사용자 혜택 → 같은 한 줄, 오른쪽에 작게 `기존 사용자 혜택`.

## 4-2. 잠긴 기능 표시 — 블러 + 가운데 버튼 (확정)

잠긴 묶음을 **흐리게(블러)** 그리고 그 위 가운데에 짧은 설명 + 민트 버튼 `평생 이용권으로 열기` 하나를 얹는다. **자물쇠 아이콘·배지는 쓰지 않는다.** 블러 영역 어디를 눌러도 프로 시트가 열린다. 흐린 항목 자체는 선택되지 않는다.

시안 원본: `.superpowers/brainstorm/75571-1792593498/content/settings-card-copy.html` 하단

| 위치 | 보이는 것 | 블러 처리 | 가운데 설명 |
|---|---|---|---|
| 알림음 선택 시트 | `기본음` 은 정상 선택 가능 | 기본음 외 프리셋 행 + "내 음원" 섹션 전체 | 알림음 전체 · 내 음원 |
| 홈 장소 목록 (무료 + 장소 1개 보유) | 등록된 장소 1개 정상 | "장소 추가" 버튼 자리에 **흐린 예시 장소 2개**(집·역 같은 가짜 행) | 장소를 더 등록하려면 |
| 백업·가져오기 메뉴 | — | 해당 메뉴 항목 | 장소 백업 · 가져오기 |

- 예시 장소 이름은 l10n 문자열로 둔다(실제 데이터 아님).
- 장소가 0개인 무료 사용자는 블러 없이 평소처럼 첫 장소를 등록한다.
- 블러는 디자인 시스템(`lib/core/ui/`)에 공통 컴포넌트 하나로 만들어 세 곳이 같이 쓴다.
- 프로가 되면 블러가 즉시 사라진다.

### 절대 띄우지 않는 곳

- 알림 화면, 알림 해제 직후, 첫 실행 온보딩 중. 광고 규칙([07](../../07-MONETIZATION.md) 정책 경계)과 같은 이유 — 급한 손이 결제를 누르게 하지 않는다.

## 5. 동작 규칙 (확정)

| 상황 | 동작 |
|---|---|
| 구매 성공 | 즉시 광고 중단·제한 해제. 재시작 불필요. 구매 확인(acknowledge)을 반드시 한다 — 안 하면 Play 가 3일 뒤 자동 환불 |
| 앱 시작 | Play 에 과거 구매 조회 → 로컬 상태 갱신 |
| 오프라인·Play 조회 실패 | **마지막 확인 상태 유지.** 오프라인이라는 이유로 프로를 빼앗지 않는다 |
| 환불·취소 감지 | 무료로 전환. **이미 등록된 장소·알림음은 지우지 않고 계속 동작**. 세부(설계자 판단): 기존 장소의 이름·반경·방향·시간대·켜기/끄기 수정과 삭제는 허용. 장소 수가 무료 상한(1) 이상이면 추가 차단(지웠다 다시 추가도 같은 규칙). 장소의 기존 알림음은 다른 항목을 고쳐 저장해도 유지, 기본음 외 **다른 음으로 바꾸기**와 내 음원 등록만 차단 |
| 복원 | "복원하기" → Play 과거 구매 조회. 같은 구글 계정이면 재설치·기기 변경 후에도 복원 |
| 결제 대기(pending, 편의점 결제 등) | 프로로 열지 않는다. 대기 중 안내 |

**로그인·서버 없음.** 구매는 Play 가 기기의 구글 계정에 묶어 기억한다. 서버 영수증 검증은 하지 않는다 **(설계자 판단** — 6,500원 단일 상품에서 위조 방어 비용이 이득보다 크다).

## 6. 기존 사용자 혜택 — 폐기 (2026-10-22, 결정 072 개정)

> 아래는 처음 설계다. 개정: 기존 사용자도 구매한다(베타 사용자로 본다). 무료 제공은 Play 프로모션 코드로만 한다 — 구매로 기록돼 구글 계정에 남는다.


이번 업데이트 전부터 쓰던 사람에게 프로를 무료로 준다. 누구인지 알 수 없으므로(로그인 없음) **기기 기준**으로 판정한다.

- 업데이트 후 **처음 실행할 때 한 번만** 판정한다(판정 완료 표시를 저장).
- 그 시점에 기기 DB 에 **장소가 1개 이상** 있으면 → "기존 사용자 혜택" 프로 부여(기기 저장).
- 새로 설치한 사람은 그 시점 DB 가 비어 있으므로 해당 없음.
- 한계: 앱을 지우고 다시 깔면 혜택이 사라질 수 있다. 문의가 오면 **Play Console 프로모션 코드**(일회성 상품을 0원에 받는 코드)로 처리한다. 코드 작업 없음.
- **Android 자동 백업**(`allowBackup` 기본 켜짐)으로 DB·SharedPreferences 가 새 기기에 복원되면 혜택·판정 완료 표시도 함께 따라온다. **(설계자 판단)** 그대로 둔다 — 복원되는 사람은 원래 기존 사용자다.
- **iOS 에서도 판정만은 이번에 실행해 기기에 기록한다 (설계자 판단).** 나중에 iOS 결제를 붙일 때 "업데이트 후 첫 실행" 기준이 그때로 밀려 이후 가입자까지 혜택을 받는 것을 막는다. iOS 화면에는 아무것도 보이지 않는다.

## 7. 구조 (설계자 판단, 빌더 재량 범위)

[02-ARCHITECTURE](../../02-ARCHITECTURE.md) 규칙을 따른다.

- 새 feature `lib/features/pro/` — domain(등급·상한 계산·혜택 판정), data(Play 결제 어댑터), presentation(프로 시트·설정 항목).
- **feature 끼리 직접 import 금지(규칙 1).** places·sounds·ads 는 pro 를 모른다. `app` 계층이 프로 상태를 읽어 값(허용 여부·상한)으로 넘기고, 막힌 경우 시트를 연다.
- 광고 억제는 `app` 계층의 기존 광고 조율 지점(`AdBannerFrame`, `AlertAdCoordinator`)에서 프로면 요청 자체를 하지 않는다. **알림 해제는 광고·결제와 무관하게 즉시 완료**(규칙 4) 유지.
- 상태 관리는 `@riverpod` codegen 만.
- 결제 플러그인은 공식 `in_app_purchase` **(설계자 판단)**.
- 로그는 `Diagnostics` 로, `[pro]` 태그: 상품 조회 결과, 구매 시작·성공·실패·대기·취소, 복원 결과, 앱 시작 시 조회 결과, 기존 사용자 판정 결과(장소 수 포함), 환불 감지, 시트를 띄운 진입점. 예외를 삼키는 자리마다 사유.

## 8. 테스트

- 등급별 상한 계산, 기존 사용자 판정(첫 실행 1회·장소 유무), 환불 시 기존 데이터 유지, 오프라인 시 상태 유지 — 단위 테스트.
- 결제 어댑터는 인터페이스 뒤에 두고 가짜로 대체해 위젯 테스트(시트 진입 4곳, 금지 3곳에서 안 뜸, 프로일 때 광고 미요청).
- 실제 결제는 Play Console **라이선스 테스터** 계정 + 내부 테스트 트랙으로 실기기 확인. 자동 테스트로 닫히지 않는다.

## 9. 사용자 작업 (코드 밖, 선행)

1. Play Console **판매자 결제 프로필** 완료.
2. 일회성 상품 생성: ID **`pro_unlock`**, 가격 ₩6,500(다른 국가는 Play 자동 환산).
3. 라이선스 테스터 등록.
4. 개인정보처리방침·데이터 보안 양식에 구매 정보 처리 반영 여부 확인.

## 10. 하지 않는 것

- 구독, 서버 영수증 검증, 로그인.
- iOS 결제(별도 작업 — App Store Paid Apps Agreement 미서명 상태).
- 알림 신뢰성 관련 기능·권한 제한.
- 무료 사용자에게 결제 유도 팝업을 주기적으로 띄우는 것.
