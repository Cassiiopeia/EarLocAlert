# 장소 루틴 묶음 (프로) — 설계

이슈 #315. 사용자 요청: "경로·루틴 묶음 기능 있으면 좋겠다, 설계가 필요해 보인다" (설계는 위임받음).

## 왜

- 출근길(집 출발 · 역 도착 · 회사 도착)처럼 함께 쓰는 장소를 날마다 하나씩 켜고 끈다.
- 출근 중에 퇴근길 장소가 울리지 않게 하려면 하나하나 꺼야 한다.

## 목표 / 비목표

- 목표: 장소 묶음(루틴) 만들기·고치기·지우기, 홈에서 한 번에 켜고 끄기, "켜면 나머지 끄기".
- 비목표: 루틴 순서 진행(다음 정류장 자동 안내 — ① 미리 알림은 사용자가 뺐다), 루틴별 시간대(장소 시간대가 이미 있다), 백업 파일에 루틴 포함(가져오면 장소 id 가 새로 생겨 묶음이 깨진다 — 다음에).
- 금지: 루틴 상태와 장소 상태가 따로 놀아 "루틴은 켜졌는데 장소는 꺼짐"이 생기는 것.

## 정한 것

1. **자리** — 루틴은 장소의 묶음이라 `features/places` 안에 둔다(`domain/place_routine.dart`). 다른 feature 를 import 하지 않는다.
2. **켜짐은 저장하지 않는다** — 묶은 장소 중 남아 있는 것이 모두 켜져 있으면 켜짐. 장소를 따로 켜고 꺼도 어긋날 수 없다.
3. **누르기** — 켜짐이면 묶은 장소를 모두 끈다. 아니면 모두 켠다. `isExclusive` 면 켤 때 루틴 밖 장소를 모두 끈다. 한 번의 트랜잭션(`setEnabledMany`)이라 감시 동기화가 한 번만 돈다.
4. **저장** — Drift v5 `place_routines`: id, name, place_ids(JSON 배열), is_exclusive, created_at. 장소를 지워도 루틴은 남고 그 id 만 무시한다. 묶은 장소가 다 지워진 루틴은 목록에서 "장소 없음"으로 보인다.
5. **화면** — 설정 > 루틴(목록) · 루틴 편집(이름, 나머지 끄기, 장소 고르기, 지우기) · 홈 장소 시트 위 칩 줄(루틴이 하나라도 있을 때만, 마지막 칩은 "관리").
6. **무료/프로** — 만들기는 `canUseRoutines`. 무료는 목록 화면이 흐린 잠금. 환불돼도 만든 루틴은 홈 칩으로 계속 켜고 끈다(075-3 과 같다).
7. **로그** — `[routine] added/updated/deleted name= places= exclusive=`, `[routine] toggled name= to=on|off changed= exclusive_off=`.

## 빌더 몫

- 칩 모양, 편집 화면 배치. 실기기 검증 필요: 한 번에 여러 장소를 켤 때 지오펜스 재등록이 한 번만 도는지.
