# 스토어 릴리스 노트 (언어별)

Play 배포는 릴리스 노트를 언어별로 올린다(`.github/scripts/prepare_play_changelogs.sh`, 이슈 #167).

- **모든 언어(ko-KR 포함)를 이 폴더의 `<언어>/<버전>.txt` 로 직접 쓴다.** 예: `ko-KR/1.19.0.txt`, `en-US/1.19.0.txt`
  - 언어: `ko-KR`, `en-US`, `ja-JP`, `zh-CN`
  - **한국어 파일이 없으면 자동 노트(`CHANGELOG.json`, 커밋 메시지 요약)가 올라간다.** 그 노트에는 문서 항목, 이슈 번호, "구현 보고서를 남긴다" 같은 **내부 문구가 섞여 스토어 사용자에게 그대로 보인다**(2026-09-29 Play Console 에서 1.18.3~1.18.5 로 확인). 그러니 배포마다 한국어 파일도 쓴다.
  - **파일 이름의 버전은 배포 시점의 `version.yml` 버전이다.** 릴리스 워크플로우가 배포 직전에 확정하므로, `feat:` 커밋이 있으면 minor 가 오른다(`semver_auto`).
  - 파일이 없으면 한국어 노트가 대신 올라간다. 빈 화면보다 낫지만 사용자에게는 그 언어가 아니다.
- 500자 이하(Play 한도). 넘으면 배포 직전에 잘린다.
- **사용자가 직접 느끼는 변화만 쓴다.** 내부, CI, 테스트 항목은 뺀다.
